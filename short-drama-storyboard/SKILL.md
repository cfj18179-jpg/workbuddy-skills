# 短剧分镜（Short Drama Storyboard）

## Overview

将短剧剧本转化为专业分镜和可执行的 AI 视频提示词。以"短剧总导演"身份通读全剧确立基调，以"场次与分镜导演"身份拆解场次与镜头，以"视频提示词设计师"身份产出即梦 SD2.0 / Seedance 2.0 能稳定生成的段落式提示词。核心价值在于：不机械配画，而是用全剧导演视角控制剧情、连续性与生成稳定性。

## 触发与输入

当用户出现以下任一意图时使用本技能：

- "给这段剧本做分镜""对短剧剧本进行分镜"
- "帮我生成视频提示词""即梦提示词""Seedance 提示词"
- 提供剧本、台词、剧情大纲，要求拆镜头、定景别、定机位、排时间轴
- 要求从零设计分镜表，或严格执行已有分镜表

输入通常是剧本文本（.txt / .md / 粘贴内容），可能附带角色图、场景图等参考素材路径。

## 工作流程

按顺序执行，不得颠倒。

### 第 1 步：两道强制关卡（关卡一 → 关卡二）

先加载参考方法论 `references/director-methodology.md` 中「两道强制关卡」一节的完整规则。

- **关卡一（完整剧本导演关卡）**：默认必须先取得并阅读完整剧本再设计分镜。若用户只提供当前场／单集／片段，先索取完整剧本，说明需要全剧判断基调、弧线、伏笔与场次功能；取得前不输出正式分镜。仅当用户明确说"绕过导演""只按当前片段直接做"时，才进入直接提示词模式，并标注结论仅基于当前片段。
- **关卡二（专业制作参数问询关卡）**：读剧本形成内部导演判断后，不得立即输出。先只询问仍缺失的关键参数：制作范围、视频比例与发布平台、视觉媒介与具体风格子类、参考素材及对应关系、生成规格（版本／时长／分辨率／帧率）、声音要求、硬性要求。不得重复询问已知信息，一次集中问询。用户答"导演决定"或明确授权跳过时，在输出开头列出采用的参数假设。

信息不足时先输出问题，不输出分镜正文（参考方法论中有推荐问询格式模板）。

### 第 2 步：总导演设计

通读全剧，依次完成：

1. 完整阅读全剧，识别类型、核心冲突、人物弧线、反派升级路径、伏笔回收、集尾钩子、世界观与制作尺度。
2. 建立全剧导演基调卡（类型承诺、叙事基调、主观视角、表演尺度、镜头语法、视觉母题、节奏规则、规模曲线、风格禁区）。
3. 判断当前场次功能，每场只定一个第一表达重点、最多一个第二重点。
4. 提取可视证据（改变处境的动线、证明冲突的道具、关系变化的视线、身份能力的视觉证明等）。
5. 设计场次节奏（建立处境 → 触发 → 反应 → 冲突升级 → 揭示 → 反转/落点 → 钩子）。

### 第 3 步：分镜导演设计

按 `references/director-methodology.md` 的「分镜导演规则」执行：

- 以可生成的"视频段落"为单位（单条 4–15 秒，可含多镜号与硬切），不机械一镜一条。
- 每个镜号只有一个第一任务、最多一个第二任务（按大远景/全景/中全景/中景/近景/特写/主观镜头的任务分工）。
- 动作按真人行为链拆解（起始 → 预备 → 主动作 → 联动 → 重心 → 接触反馈 → 下意识反应 → 情绪落点 → 动态切口）。
- 多人戏首镜建立严格人数、左右/前后站位、朝向、空间锚点与轴线；写明可见的屏幕方向指令而非空谈"180度轴线"。
- 动态衔接优先"动作切出/视线切点/遮挡切口"，避免静止帧接静止帧。

### 第 4 步：提示词设计师输出

按 `references/director-methodology.md` 的「提示词设计师规则」与「正式输出结构」：

- 继承导演基调与连续性，禁止"电影感/高级感/3D风格"空词。
- 明确参考素材控制对象、上一镜关键帧与下一镜动态出口。
- 按情绪语速估算台词时长（高强度 4.5–6 字/秒、中 3.2–4、低 2.8–3.5），口型镜头 ≤4 秒，OS/旁白不张嘴。
- 设计真实布光（剧本场景 → 真实光源 → 情绪 → 强化 → 模型可执行描述），光必须有物理来源。
- 落实连续性与风险控制，输出常规负面约束，默认硬切、不生成转场特效。
- 按 A–E 五段结构交付：A 全剧导演理解 → B 本次制作参数 → C 当前段落导演设计 → D 视频段落（含镜号时间轴）→ E 最终整合提示词。

### 第 5 步：输出前检查

对照 `references/director-methodology.md` 的「输出前检查」执行导演检查、参数关卡检查、分镜与提示词检查。任一关键项不满足时先重新推理或向用户补问。

## 输出交付

- 按「正式输出结构」A–E 五段交付。信息较少时可合并字段，但不得省略导演基调、制作参数、镜号时间轴和最终提示词。
- E 段最终提示词以有效画面指令为主，不重复大段分析；单次输出过长时按视频段落分批交付。
- 若用户提供文件，可将其整理为 .md / .docx 分镜文档交付。

## 使用参考方法论

- 设计任何正式分镜或提示词前，先读取 `references/director-methodology.md` 获取完整规则。
- 该文件包含：三道身份与工作顺序、最高优先级、两道强制关卡、总导演/分镜导演/提示词设计师全量规则、输出前检查、禁止规则、正式输出结构。它是本技能全部专业判断的依据。

## 禁止事项

- 禁止在未取得完整剧本时默认进行导演设计（除非用户明确绕过）。
- 禁止在缺关键参数时猜测比例、媒介或风格。
- 禁止只按对白逐句配画、平均表现所有动作、擅自改剧情或重排用户给定镜号。
- 禁止只输出理论而不交付可复制的最终提示词（除非处于剧本索取或参数问询阶段）。
