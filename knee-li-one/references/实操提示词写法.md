# 实操提示词写法（即梦 / Seedance 图生视频喂入格式）

> 本文件是 `knee-li-one` 的「实操落地层」规范（继承自 `knee-li`），依据用户第57集《生成时所用分镜提示词.txt》提炼。与「设计层」（md 六段式分镜文档）是上下游关系：设计层定"拍什么"，实操层定"怎么喂给模型"。

---

## 0. 设计层 vs 实操层

| 层级 | 载体 | 用途 | 单位 |
|---|---|---|---|
| 设计层 | 分镜设计 .md | 导演分析 + 镜号时间轴 + 整合提示词草稿 | 视频段落（6–8 段） |
| 实操层 | 生成提示词 .txt | 真正粘贴进即梦/Seedance 的喂入文本 | 分镜时序（8–12 条，比设计层更细） |

实操层把设计层的一段，拆成多条「分镜时序」，每条对应一次生成任务，用 `@素材` 引用参考图/音频，用电影语言写镜头。

---

## 1. 单条「分镜时序」结构

```
分镜时序N
要求：<风格子类 + 画面不出现字幕 + 表演约束>
<素材定义块：@素材 是 定义 / 音频参考@xxx>
- 光影：<真实布光>
位置 / 轴线母版：<站位与朝向>
附加：<空间关系参考 + 大小对比 + 明示不做首帧>
镜头1 / 镜头2 / 镜头3 …：<电影语言镜头描述>
要求 / 注意：<结尾负面约束>
```

要点：每条开头必写「要求：画面中不出现字幕，视觉媒介…具体风格子类…」，结尾再写一条「要求/注意」收束约束。素材定义块和站位描述放在镜头描述之前，让模型先"认得人、站好位"，再"动起来"。

## 2. 素材引用语法

### 2.1 图片（锁身份/场景/道具/状态）

```text
@东海上空云路 是上空云海
@林玄面部参考 是林玄的面部参考
@林玄身材参考 是林玄的身材参考
@林玄睁眼 是林玄开启洞察之眼的状态
@熬广 是敖广
@禁制球 是禁制球
@祖龙鳞 是祖龙鳞，是衰弱状态
```

- 一个角色可有**多张图对应多个状态**（林玄：`@林玄面部参考` 正常态 / `@林玄睁眼` 洞察之眼态），需分别声明。
- 道具可声明**附加状态**（祖龙鳞「是衰弱状态」）。

### 2.2 音频（锁声线口型）

```text
林玄音频参考@男主声音
秦渊音频参考@秦渊声音
敖广的音频参考@敖广
```

### 2.3 空间关系图（仅站位参考，严禁做首帧）

```text
@1 与 @2 是四人在上空云海中的位置关系图，仅做位置关系参考，不做单帧、首帧参考
林玄与敖广的空间关系参考@3。这里不做首帧、单帧参考，不参考该图质感，仅做空间站位关系参考
@02 与 @01 都是制作位置参考，不做任何阶段的单帧或首帧参考
```

- 站位图/关系图**只用来交代"谁在左、谁在右、谁在中间、距离多远"**，必须显式声明「不做单帧/首帧参考」「不参考该图质感」。
- 这类引用通常指向 `帧/` 目录下的站位图（如站位图.png、01.png、02.png）。

## 3. 电影语言（镜头描述规范）

### 3.1 关系拍（过肩 / 过道具前景）

```text
过敖广的右肩背面关系拍林玄
过禁制球前景虚焦关系拍林玄
过林玄的右肩背面关系拍
```

模式：`过 <前景物> 的 <位置> 关系拍 <主体>`，同时交代前景是虚焦还是实焦。

### 3.2 机位与运镜

- 机位：微仰拍 / 正面平拍 / 侧拍 / 手持近景 / 90度垂直正顶式 / 过肩背面
- 运镜：缓推 / 手持跟随 / 跟摇 / 平移跟随 / 下摇跟随 / 轻微推近 / 镜头加少量震动感
- 固定：镜头固定住（表示该镜结束时的静止落点）

### 3.3 焦点转换（精确指令）

```text
此时镜头开始缓慢变为前景实焦，林玄虚焦
当敖广说道"竟然是旧秩序的手段"的时候，焦段再次从实焦（禁制球、祖龙鳞、敖广）转为实焦（禁制球和祖龙鳞）虚焦（敖广）
丞相跪下后镜头转为虚焦禁制球，实焦丞相
```

焦点转换必须**绑定到某个动作/台词节点**（"当…的时候"），让变焦有剧情依据。

### 3.4 动作链与承接

```text
承接上一个镜头，…
镜头7：正面近景拍敖广，承接上一个镜头，（继续伴随林玄画外音：…）敖广露出略微震惊的神情
```

跨镜用「承接上一个镜头」明确连续性；画外音用「继续伴随…画外音：…」标注，不张嘴。

### 3.5 特效与转场

```text
四人化作四道流光扎进海面
一道流光从画面上方落到@反打 中
三条巨龙虚影流光般幻化出现在林玄身后
然后缓慢黑屏2秒左右（黑屏时3声带有龙吟的战鼓响声音效）
```

特效用「流光/虚影/幻化」描述；特殊转场（黑屏）要写清时长 + 期间的音效。

## 4. 关键约束（用户独门，实操层必须带）

1. **无字幕**：每条开头「画面中不出现字幕」。
2. **表演自然**：「人物表情自然，动作自然，镜头中的人物动作自然」。
3. **看向主体**：「镜头中主体说话时，其他镜头中出现的背景人物看向镜头主体（注意出现的才这样，不因为这个约束强行将每个人物都放在镜头中）」——背景人物看说话者，但**不强行让所有人入镜**。
4. **严格人数**：「出现的参考素材人物只有 5 人，不多出现」「参考素材人物严格只出现一个」——明确上限，防多生。
5. **状态保持**：「林玄转为开启洞察之眼后一直保持」「林玄转为正常状态后便一直保持额头为印记状态」——状态一旦切换就锁死，不反复跳。
6. **道具唯一与大小**：「禁制球、祖龙鳞均保持只有一个，且大小符合」「祖龙鳞大小与禁制球大小相似」——防复制、防比例漂移。
7. **站位不改**：「带到关系位置的人物不因镜头关系问题强行转向主体，保持原本站位不改动」——关系镜头里配角保持原朝向，不被镜头"吸"过去。
8. **空间关系图用途限定**：「不做单帧/首帧参考，不参考该图质感」。

## 5. 输出前自检清单

- [ ] 每条「分镜时序」是否以「要求：画面中不出现字幕…」开头、以「要求/注意」收尾。
- [ ] 素材定义块是否 `@素材 是 定义` 齐全（含多状态角色、道具附加状态）。
- [ ] 音频是否 `音频参考@xxx` 声明到位。
- [ ] 站位/关系图是否显式声明「不做单帧/首帧参考」。
- [ ] 镜头是否用「承接上一个镜头」衔接，焦点转换是否绑定动作/台词节点。
- [ ] 结尾约束是否覆盖：人数上限、状态保持、道具唯一与大小、站位不改、表演自然。
