# 一镜到底 · 前景遮挡接缝法（当剧本要求「严格一镜到底」而生成引擎有单条时长上限时使用）

> 适用场景：剧本明确写「一镜到底／长镜头流畅跟拍」，但生成引擎（Seedance 2.5 / 即梦等）单条上限 28–30 秒，
> 必须切成若干条生成再拼接，而用户要求**成片看不出任何剪辑点**。
> 核心结论：**用「前景物完全遮满画面」的一帧当接缝，而不是用硬切或叠化。**

---

## 1. 为什么遮挡能隐藏接缝

接缝的两侧来自两次独立生成，必然存在细微差异：色温、曝光、运镜速率、运动模糊量、噪点。

- 硬切 / 叠化：观众会看到两幅"有细节的画面"之间的不一致 → 露馅。
- 遮挡帧：接缝帧被一片**完全糊满镜头的虚焦前景物**占据，画面里没有任何可辨认的细节（没有五官、没有建筑线条、没有明暗结构），只剩一片同色系的柔光。此时两次生成之间的任何色差、抖动、速率差，都会被视觉系统自动解释为"同一片叶子／羽毛／布料在镜前继续移动"。

**判据**：接缝帧必须是"满屏、虚焦、单色系、无可辨认结构"的一帧。只要还有清晰边缘，接缝就会被看见。

---

## 2. 遮挡物的选择原则

遮挡物必须满足四条，缺一不可：

1. **在场**：它本来就长在这个场景里（花枝、藤蔓、门帘、袖口、翅膀、水花、人群肩背），不是凭空加的特效。
2. **可动**：能被"镜头自身的移动"带出遮挡，而不是靠它自己飞过来。
3. **可复现**：同一个遮挡物能连续出现两次——上一条的结尾与下一条的开头是它同一个动作的上下半段。
4. **不夺戏**：它是前景，始终虚焦，不承载表演。

一镜到底里推荐用**两种以内的遮挡物**，其中至少一种反复出现，形成视觉语法（观众会记住"哦，又是一枝花扫过"），比每次换一种更不容易被察觉。

---

## 3. 标准写法：接缝处一分为二

把一次遮挡拆成两条，分别写在两条提示词里，参数必须完全一致。

**上一条的最后一个镜头**：

```
镜头N（末）｜遮挡转场
镜头顺势上摇并微微后拉，把拱廊顶端垂落的长藤带进画面顶部。
一枝垂得很低的长藤（离镜头约15厘米，起始严重虚焦）随镜头运动
由画面左上方向右下横扫——花瓣擦过镜心成为一片酒红虚焦色块，
叶片糊满画面，最后整枝完全遮住镜头，只剩深红暗部与叶缝漏出的几点月光。
本条收在"画面被花枝完全遮满"这一帧，不做任何淡出、不做任何定格。
```

**下一条的第一个镜头**：

```
镜头1（起）｜遮挡解除
本条首帧即上一条的结束帧：满屏虚焦枝叶。保持完全相同的运动方向、
速度与焦段——同一枝长藤继续向右下扫出画面，焦点由虚转实：
先露出尖拱与藤架，再露出花坛与石阶，最后整幅场景清晰。镜头不减不停。
```

三处对齐，接缝就消失了：**同一物、同方向、同速率、同焦段**。

---

## 4. 接缝帧的制作与操作流程

1. 生成第 ① 条 → 导出**最后一帧**（满屏遮挡）→ 存为 `首帧_②.png`
2. 生成第 ② 条时把 `首帧_②.png` 作首帧图（i2v）；②的第一个镜头已写明"首帧即上一条结束帧"
3. 导出 ② 的最后一帧 → 存为 `首帧_③.png`，依次类推
4. **接缝处不加叠化、不加淡化、不加任何特效**。遮挡帧本身就是遮罩。
   若偶有极轻微跳变，最多做 3–4 帧交叉溶解，绝不做 12 帧以上的叠化。
5. 把相邻两条的**首帧与尾帧都设成同一张遮挡图**，可进一步强制速率趋同。

---

## 5. 前景遮挡的第二种用途：视觉节拍器

遮挡不必只在接缝处出现。在一条内部，让前景物**有节奏地扫过**，可以制造"人在场景里穿行"的体感，也让换段时的遮挡不显得突然。

常用节拍器（每 2–4 秒一次，务必虚焦、快速、不抢戏）：

| 场景 | 前景节拍器 |
|---|---|
| 花园 / 庭院 | 垂枝、花丛、藤架立柱、推开的花枝 |
| 宫廷 / 室内 | 门框、帘幕、立柱、悬灯、路过的侍从肩背 |
| 市集 / 街巷 | 摊位布幡、行人肩背、挂旗、牲口 |
| 水面 / 池边 | 溅起的水花、飘落的花瓣、水面波纹的反光 |
| 天空 / 飞行 | 翼尖掠过、云絮、坠落的羽毛、飞散的尘 |
| 群戏 | 四周围观者的肩背与衣料（镜头从人缝里穿过） |

**规则**：节拍器遮挡控制在 0.3–0.8 秒，只做"擦一下"，不要糊满；只有接缝处那次才允许"糊满"。

## 6. 时长切分原则

- 单条 ≤ 引擎上限（Seedance 2.5 / 即梦取 28 秒更稳），且 **每条都必须落在一个"甜宠节拍 / 情绪节拍"的完整收束点上**，不要在动作中途断。
- 不要在每条里塞满角色出场。**一条 2–3 人上限**（防崩脸），把"四夫同框"这类多人数镜头压成虚焦前景或不露正脸。
- 单条太短（<12 秒）会显碎，太长（>28 秒）会崩；合理区间 18–28 秒。
- 结尾的"重头戏"（如直视镜头说关键台词）要单独占一条，且给它留足 5 秒以上，不要和拉远、特效挤在一起。

---

## 7. 台词在接缝处的处理

- **VO / OS 可以自由跨越接缝**（它不上嘴，不受接缝影响），是最省事的连贯手段——用一长段 VO 串起两三条，观众感知到的就是"一直在讲"。
- **对口型的台词必须完整落在同一条内**，且 ≤4 秒；口型镜是全片唯一禁止跨接缝的东西。
- 长 VO 需要拆段时，只能按时长切，**一个字都不能改**；拆段点选在破折号、句号、逗号这类自然停顿处。
- 其余台词一律"声画分离"：开口给一秒，随后立刻切到听者反应／环境空镜／相关道具特写。
