# 短剧分镜（knee-li-one · 含镜头级因果链补全）

## Overview

这是 `knee-li` 的升级版。它在 knee-li 已有的能力（三层工作流、两道强制关卡、场次级衔接补全、Seedance 落地）基础上，补上了 knee-li 没做透的一环：

**镜头级因果链补全**：knee-li 的「衔接补全」只解决**场次级**留白（集首、场景跳、台词拆段、人物去向、情绪动作），但漏了**镜头级**留白——两个相邻镜头之间，一个"因"到"果"中间缺了**过程交代镜头**，导致能量/动作/状态"瞬移"，观感突兀不合理。

核心价值：不机械配画，也不只停留在"导演分析"，而是用全剧导演视角控制连续性，用"场次级衔接补全"解决剧本留白、用"镜头级因果链补全"解决镜头间缺过程，最终输出前后连贯、因果清晰、Seedance 2.5 能稳定生成的段落式提示词。

## 工作流程

按顺序执行，不得颠倒。

### 第 1 步：两道强制关卡（关卡一 → 关卡二）

- **关卡一（完整剧本导演关卡）**：默认必须先取得并阅读完整剧本再设计分镜。若用户只给当前场/单集/片段，先索取完整剧本；取得前不输出正式分镜。仅当用户明确说"绕过导演""只按当前片段直接做"时，才进入直接提示词模式，并标注结论仅基于当前片段。
- **关卡二（专业制作参数问询关卡）**：读剧本形成内部导演判断后，不得立即输出。先只询问仍缺失的关键参数：制作范围、视频比例与发布平台、视觉媒介与具体风格子类、参考素材及对应关系、生成规格、声音要求、硬性要求。不得重复询问已知信息，一次集中问询。

信息不足时先输出问题，不输出分镜正文。

### 第 2 步：总导演设计

通读全剧，依次完成：识别类型/冲突/弧线/伏笔/钩子 → 建立全剧导演基调卡 → 判断当前场次功能（每场一个第一重点）→ 提取可视证据 → 设计场次节奏。

### 第 3 步：场次级「剧本衔接合理性补全」（继承 knee-li）

加载 `references/衔接合理性补全.md`，按五类逐项检查并补全：集首衔接、场景跳跃补桥接、台词拆段、未出场人物去向、情绪外化动作。**边界**：只补过渡与逻辑，不增删人物、不改台词、不改剧情。

### 第 4 步：镜头级「因果链补全」（本版核心新增）

加载 `references/镜头级因果链补全.md`，对**每一对相邻镜头**执行「因→过程→果」三段检查：

1. **能量传导**：能量/光/电流/法力的变化，是否补齐"源头亮起→沿路径蔓延→末端响应"的蔓延镜头。
2. **动作轨迹**：动作是否补齐"起手→轨迹→落点"的运动过程。
3. **状态渐变**：睁眼/坐起/变形/崩解是否补齐"半程渐变"镜头。
4. **空间位移**：跨位置位移是否补齐"移动中"镜头。

**核心判据**：问一句——"这个变化，观众能看到它一步步发生吗？" 缺了就补一个 1–3 秒的过程镜头，并显式标注「本版补全·过程镜头」。

### 第 5 步：分镜导演设计

- 以可生成的"视频段落"为单位（Seedance 2.5 单条 ≤28 秒，可含多镜号与硬切），不机械一镜一条。
- 每个镜号只有一个第一任务、最多一个第二任务。
- 动作按真人行为链拆解（起始 → 预备 → 主动作 → 联动 → 重心 → 接触反馈 → 下意识反应 → 情绪落点 → 动态切口）。
- 多人戏首镜建立严格人数、站位、朝向、空间锚点与轴线；写成可见的屏幕方向指令。
- 动态衔接优先"动作切出/视线切点/遮挡切口"，避免静止帧接静止帧。

### 第 5.5 步：一镜到底的遮挡接缝设计（**按需**，仅当剧本写"一镜到底/长镜头"且引擎有单条时长上限时执行）

加载 `references/一镜到底遮挡接缝法.md`。要点：**用"前景物完全遮满画面"的一帧当接缝，而不是硬切或叠化**。三处对齐——同一物、同方向、同速率、同焦段；上一条收在满屏虚焦遮挡帧，下一条首帧即该帧。接缝帧必须"满屏、虚焦、单色系、无可辨认结构"，且接缝处明令禁止叠化/淡化/闪白/划像。遮挡物须来自场景本身、全场 ≤2 种、至少一种反复出现（同时兼作贯穿全片的"视觉节拍器"）。VO 可自由跨接缝，对口型台词必须完整落在单条内且 ≤4 秒。

### 第 6 步：提示词设计师输出（Seedance 2.5）

- 继承导演基调与连续性，禁止"电影感/高级感/3D风格"空词。
- 明确参考素材控制对象：哪张图锁哪个角色/场景/道具，哪条音频锁谁的声线口型。
- 按情绪语速估算台词时长（高强度 4.5–6 字/秒、中 3.2–4、低 2.8–3.5），口型镜头 ≤4 秒，OS/旁白不张嘴。
- 设计真实布光，光必须有物理来源。
- 落实连续性与风险控制，输出常规负面约束，默认硬切、不生成转场特效。
- 产出分两层（按用户需要交付其一或两者）：
  - **设计层**：六段式分镜文档（A 全剧导演理解 → B 本次制作参数 → C 段落导演设计+衔接补全 → D 视频段落分镜表 → E 最终整合提示词 → 附：资产对应总表 & 风险提示）。
  - **实操层**：把设计层的一段拆成多条「分镜时序」，按 `references/实操提示词写法.md` 的喂入格式输出。

### 第 7 步：输出前检查

- 导演检查：是否读完完整剧本、理解全剧弧线与当前场位置、每场单一重点、可视证据充分、未提前泄露后续剧情。
- 参数关卡检查：制作范围/比例/媒介/风格子类/素材/时长/声音/硬性要求是否确认。
- 场次级衔接补全检查：五类衔接是否已检查、每条是否标注"本版补全"、是否守住边界。
- **镜头级因果链检查（新增）**：每一对相邻镜头是否过了"因→过程→果"三段检查；能量/动作/状态/位移的变化是否补齐过程镜头；过程镜头是否控制在 1–3 秒、标注"本版补全·过程镜头"。
- 分镜与提示词检查：人数与画外方位、场景天气道具服装连续、新镜起点承接上镜结束状态、口型与 OS 规则、屏幕左右/视线/过肩归属、光源真实稳定、结尾有动态出口、负面约束齐全。

任一关键项不满足时先重新推理或向用户补问。

## 输出交付

- 设计层按六段结构交付，信息较少时可合并字段，但不得省略导演基调、制作参数、镜号时间轴和最终提示词。
- 实操层按「分镜时序」分条交付，每条一个生成任务，开头必带「画面中不出现字幕」、结尾必带人数/状态/道具/站位约束。
- 新增补全段落用「**本版补全**」标记，镜头级补全额外标注「**过程镜头**」，单独汇总，方便用户一眼看出你补了什么、随时回退。
- E 段最终提示词以有效画面指令为主，不重复大段分析。

## 使用参考方法论

- 场次级补全：读取 `references/衔接合理性补全.md`（五类衔接补全规则与实例）。
- **镜头级补全：读取 `references/镜头级因果链补全.md`（四类过程交代镜头 + 三段检查法，本版核心）。**
- 实操喂入格式：读取 `references/实操提示词写法.md`（@素材引用语法、电影语言镜头、人数/状态/道具/站位约束）。
- **一镜到底接缝（按需）：读取 `references/一镜到底遮挡接缝法.md`（前景遮挡接缝、遮挡物选择四原则、遮挡节拍器、时长切分、跨接缝台词规则）。**
- 三层导演规则、两道关卡、输出前检查的完整版见旧 skill `short-drama-storyboard` 的 `references/director-methodology.md`。

## 禁止事项

- 禁止在未取得完整剧本时默认进行导演设计（除非用户明确绕过）。
- 禁止在缺关键参数时猜测比例、媒介或风格。
- 禁止只按对白逐句配画、平均表现所有动作、擅自改剧情或重排用户给定镜号。
- 禁止补全时增删人物、改写台词、篡改剧情或提前泄露后续伏笔。
- 禁止把补全写成抽象说明，必须落成具体画面/站位/运镜/台词。
- **禁止镜头间"因→果"直接跳切而缺过程镜头**（能量瞬移、动作跳帧、状态突变、位移缺失都必须补）。
- **禁止过程镜头喧宾夺主**（控制在 1–3 秒，是"交代"不是"展开"）。
- 禁止只输出理论而不交付可复制的最终提示词（除非处于剧本索取或参数问询阶段）。
- **禁止在一镜到底里用硬切/叠化/闪白去拼接 30 秒分条**——必须用前景遮挡帧隐藏接缝（见 `references/一镜到底遮挡接缝法.md`）。
- 禁止把站位关系图当作首帧/单帧参考。
- 禁止遗漏实操层的核心约束：画面无字幕、严格人数上限、角色状态保持、道具唯一与大小、站位不改、表演自然。
