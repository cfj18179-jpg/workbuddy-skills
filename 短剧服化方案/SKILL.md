# 短剧服化方案与造型提示词

## 何时用

用户给出剧本（或已在前文给出）并要求「整理服化方案 / 每个角色的造型 / 服装方案」，通常还会给一份**造型分档**（如：陈康 1/2/3 + 鹰眼术；安雅 1日常劳作/2出门体面/3居家；猴子 1混混日常/2赶海工作装/3出门显摆）。若用户没给分档 → **先按"身份变化 + 场景变化"给每个角色设计 3 档**，并在总表里让用户一眼能改。

## 交付物结构（3 件套）

1. **〇 服化方案总表**：`| # | 角色 | 造型① | 造型② | 造型③ |` 一行一角色，覆盖全剧角色（含群像泛角色）。**不设「特殊状态」列**（见下方铁律）。
2. **一 通用规则**：排版句 + 质感句 + 统一限制（见下），一次写明，各卡内逐条内嵌不省略。
3. **二 逐角色服化卡**：每角色一张，含【面容锚点】【发式系统】+ 每造型【服装层次（内/中/外/下/足/配饰）】+ **每造型一段完整提示词**。

## 角色服化卡格式

```
===== 服化卡 NN · 角色名 =====
【面容锚点】五官结构（禁止任何表情神态词）
【发式系统】发长/发质/发型/是否烫染
【造型① 名称】（场景或身份一句话）
服装层次：内＝…；中＝…；外＝…；下＝…；足＝…；配饰＝…
【提示词①】真人电影级人物摄影，…（角色描述 60 字内）…服装：…。角色资产卡排版——…（排版句）。真人电影级人物摄影…（质感句）…（限制句）。
【造型② …】…
【造型③ …】…
```

## 必须逐字内嵌的固定句（用户项目惯用）

**排版句（紧凑版，约 150 字，每条提示词都要有）**
角色资产卡排版——纯白背景不出现文字；左半 2/5 上下两张头肩特写（上＝正面、下＝45 度正侧面展示左脸侧颜，头部占格子高度约 7 成、头顶到下巴完整不裁切、四周仅少量边距），脸部平静中性、不笑不动情、嘴角平直；右半 3/5 三个全身立绘（自左至右＝正面、90 度正侧面、背面），头部与脖子必须完全移除、颈部领口空出，保留完整躯干、双臂、双手（十指清晰）与双腿，双手自然下垂贴于体侧，侧面立绘为标准 90 度正侧面、脚尖与胸口朝画面左边缘、仅见左手臂、双腿并拢重叠，禁止朝右、3/4 侧面与 45 度侧背；三个立绘等高等宽等间距，脚底同线、肩线同高、领口同高，如同原地转身；所有格子服装、配色、配饰完全一致。

**质感句**：真人电影级人物摄影，{年代}年中国{地域}，真实皮肤纹理（毛孔、晒斑、细纹、汗光，不磨皮不美颜），柔和均匀棚拍主光＋轻微轮廓光，低饱和自然褪色胶片色带轻微颗粒，8K 超精细。

**限制句**：禁止二次元／动漫／3D 建模／游戏 CG／插画／油画；禁止现代服装与现代物品；禁止磨皮美颜、塑料皮肤、浓妆、夸张表情；禁止多余人物、身体残缺、断肢、乱手多指；禁止文字、字幕、水印、签名、logo；禁止背景非纯白与投影地面。

## 造型设计方法论（关键，决定成品质量）

同一角色三档造型必须**用可一眼分辨的客观变量**拉开，不要只换颜色：
- **面料新旧**：洗旧泛黄／补丁 → 半新 → 新布挺括有折痕
- **是否打理头发**：油乱未洗 → 自然 → 发蜡发胶油头（还可做"学不像"的喜剧感）
- **鞋**：拖鞋／人字拖 → 解放鞋／雨靴 → 擦亮皮鞋（鞋是身份最直接的信号）
- **配饰**：无 → 塑料／红绳 → 假金链／手表／戒指（年代感＝廉价仿货）
- **结构物**：围裙／袖套／防水围裙的有无（劳作 vs 出门 vs 居家）
- 特殊状态（法眼变色、挑担、穿新衣、湿身）**不单列成资产卡档，也不进服化方案总表**；换装类的可并入造型档，纯技能/情绪/受伤类一律移交分镜·视频层。

**铁律（用户 2026-09 明确要求，优先级最高）**
1. **所有角色资产卡一律「常规正常状态」**：卡片字段里**不设【特殊状态】栏**；提示词中**不写伤妆、血渍、包扎绷带、淤青、擦伤、擦痕、结痂、旧疤、痘坑之类**会随时间变化的体表特征（痘印/晒斑属于常态肤质，可保留）；不叠加技能效果、情绪神态、湿身、夜色等状态。
2. 剧情性的受伤、换装、技能特效 → **只在分镜／视频层实现**，不要写进资产卡；若用户单独要，做成文末「附录：技能特效参考（非资产卡）」。
3. **面容差异一律写「无（面容与锚点完全一致）」**——同一角色跨造型只在服装/鞋/配饰上变化，左半两张头肩特写必须逐像素一致。
4. 分档命名不要带状态词：写「① 开篇街溜子」，**不要**写「① 开篇街溜子／伤后日常」。

**硬规则**：同一角色**左半两张头肩特写在各造型间完全一致**，造型差异只落在右半三张无头全身立绘的服装/鞋/配饰；没有任何例外可以改头肩特写（技能特效已移出资产卡）。

**单角色调性变更必须全量同步（高频需求，必须做全）**
用户常在中途给某个角色补一句定调，例如「陈康的脸上要干净」「李艳丽的服装要干净青春、长相要清纯、衣服不张扬」。这类指令**不能只改一处**，必须一次性同步以下全部位置，否则跨卡出图会前后矛盾：
1. 主册该卡的【基础面容锚点】【发式系统】【服装层次】＋【中文AI提示词】；
2. 服化方案册该角色的【面容锚点】【发式系统】＋**全部造型**的服装层次与提示词；
3. 主角团三版册的**每一条备选版**（A/B/C 全部）+ 常规服装段 + 选型对照表里该角色那行 + 相关选型原则；
4. 总表（若改了造型名）。
**做法**：先按关键词+角色名把全部命中位置列出来（避免漏改），再用脚本一次性替换，最后用**反向关键词扫描**验证——把旧调性的元素词列成黑名单（如「浓妆/口红/正红/离子烫/发卡/紧身/无袖/短裙/细跟/亮片/金饰/烫发/大波浪」），扫描该角色区块确认清零（注意区分其他角色与「不戴耳环」这类否定句）。改完重出 docx。

**单角色「多套备选装」的交付模式（高频追加需求）**
用户常在中途要「给我几套 X 角色某场合换衣服的提示词」（如「安雅出门办事的几套衣服」）。这不是新造型档，而是**同一档位的多套服装备选**，按以下规格做：
1. **面容与发式全部锁死**：N 套共用同一组【面容锚点】与同一款发型，【面容差异】统一写「无（面容与锚点完全一致）」；差异**只落在右半三张无头全身立绘**上。
2. **差异只用四个客观变量拉开**：**面料**（的确良／棉布／针织／西裤料／两用衫料）、**领型**（衬衫领／翻领两用衫／开衫叠穿）、**下半身**（西裤／及膝半裙／宽松长裤）、**鞋**（布鞋／低跟皮鞋／凉鞋）。**不要靠换颜色**——否则出图后像加了个滤镜，不像换了衣服。
3. **色彩区间接角色人设定死**（如素净型角色压在白／浅蓝／浅灰／米／藏蓝内），并在交付里写明**风格底线**（不许亮色、大花、无袖、紧身、短裙、高跟、浓妆口红、金饰叠戴）。
4. **编号沿用「主卡号-造型字母+序号」**（如 02-B 之后续 02-B1…B5），并在交付开头给**选型对照表**（编号｜名称｜一句话定位｜最贴的场合｜推荐）。
5. **持物例外必须单独标注**：需要提包/提桶的方案写「**本造型例外**」并附一句「若不需要持物，删掉此句即为标准双手自然下垂」；不需要持物的严格双手下垂贴体侧。
6. **出图顺序写进交付**：先出基准款（最正的那套）定脸定色，再拿它的左半两张头肩特写当参考图出其余套。
7. **要顺带说清与既有造型卡的关系**（新方案是替换还是对照），并给出「想更素净／更显精神／换季节」的三句改法，方便用户自己微调。

**「降年龄感」改法（用户高频反馈：不要老气、可以稍微潮流一点但不要太张扬）**
反馈常出现在中年以下角色身上。**关键：不要靠加颜色或装饰来"变年轻"**（那会直接变成"张扬"，违反不张扬的底线）。正确做法是**只改版型、领型、结构、面料、鞋、发饰**六样：
| 老气（弃） | 年轻（用） |
|---|---|
| 的确良／涤棉／西裤料 | 纯棉 T 恤、棉麻、细针针织、水洗牛仔 |
| 单件衬衫扣到第二颗 | T 恤、小方领、衬衫**袖口挽起一道**、**背带裤/背带裙**、开衫**系腰** |
| 直筒**西裤** | 直筒**牛仔裤**、及膝直筒半身裙、锥形休闲裤 |
| 黑色低跟系带布鞋／方口布鞋 | **白色低帮帆布球鞋（回力样式）**、米白低帮布鞋 |
| 深色／铁质发夹 | **素色发圈、发带**（年轻人用发圈，长辈才用发夹） |
| 细银链等首饰 | 细带女表、棉麻单肩包、藤编手提袋 |

配套动作：① 在交付里给一张「老气版 vs 年轻版」对照表，让用户一眼看到改了什么；② 把**色彩区间写死不变**（仍压在白／浅蓝／浅灰／米／卡其／藏蓝内），并重申底线（无亮色、无大花、不紧身、不露腰、不无袖、不短裙、不高跟、不浓妆、不金饰）；③ 若角色是"穷但年轻"，**牛仔裤＋白T＋帆布鞋**是 1998 年中国最准确也最省钱的年轻装，优先用；④ 提醒一句：**若只要求改服装，就别顺手改面容**（显老的黑眼圈/细纹/面颊消瘦属于"操劳感"设定），但要主动问用户是否连脸也要减龄。
**例外**：为让造型与场景对得上，允许个别造型持物（端碗、提桶、挑扁担、扶鱼竿、拿账本），须在该造型内标注"本造型例外"，其余一律"双手自然下垂贴于体侧"。

**泛角色（村民甲/乙/丙、妇女甲乙、老嫂子、老人、孩子、村民）**：按单一代表人物出卡（配合"同一人原地转身"的无头立绘）；若用户要群像变体，改为"同一格内并排 3 个不同人物，服装风格统一为该年代"。

## 技术路径（本机已验证）

1. **读剧本**：本地 Office 编辑通道**没有整篇文本读取接口**（只有逐节点结构查询，长剧本不实用）→ 用 `markitdown` 把 docx 转 md 再做角色上下文抽取（按人名 grep、统计出现次数、抓 Δ 行动描写与台词）。用前要向用户报备这个降级。
2. **写交付 docx**：走 `tencent-local-office-edit` 的 `edsdk.py`：
   - `python3 edsdk.py call create_doc` → 拿 file_id（**解析时用 `grep -oE "file_id=[A-Za-z0-9_]+" | head -1 | cut -d= -f2`，输出里 id 会出现两次，直接 grep 会带换行导致后续报 `document is not open`**）
   - 长中文内容用 `--json-file` 传 `{"file_id":…, "idx":0, "base64_markdown":"<base64>"}`（UTF-8 JSON，避免 shell 引号/编码问题）
   - `doc_insert_markdown` → `save_file`（`file_path` 指向项目目录）
3. **大册拆分**：单次生成 60K+ 字时，分 3~4 个 Write 写成 part 文件，再用 python 拼接、统计（`md.count("===== 服化卡")`、`md.count("【提示词")`）后入库。
4. **校验**：生成后用 markitdown 反读 docx，确认字符数与卡片数一致。

## 收尾

- 明确写出**例外清单**（哪些造型持物）与**出图顺序建议**（先出造型②定脸，再以头肩特写为参考图出①③）。
- 用户没给名称的造型档要**明确标注为推断**并请其确认。
- 结尾给"可继续扩的方向"清单（如雨夜湿身版、丧服版、结局西装版）。
