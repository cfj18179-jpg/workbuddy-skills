# 剧本衔接合理性补全方法论

> 本文件是 `knee-li` 的核心新增能力，依据用户第57集分镜设计（v2 版）的实战手法提炼。目的是把"剧本留白处"在分镜阶段主动补圆，让前后镜头衔接自然、逻辑自洽。

---

## 0. 为什么需要"衔接补全"

剧本是文字，读者用想象补全；视频是连续的时空画面，任何跳跃都会被观众立刻察觉。剧本作者常在这些地方留白：

- 场景切换时，没写"人是怎么进去的"（从海上 → 直接到了龙宫正殿）。
- 多人同行时，只写主角，没交代"其他人去哪了"。
- 一句长台词，作者写在一行，但视频里口型镜头撑不了那么久。
- 一个强烈的心理状态（震怒、恐惧、错愕），只有台词没有可见动作。

分镜导演的职责之一，就是**在不改动剧情与台词的前提下，把这些留白补成可拍的过渡与动作**。这就是"衔接合理性补全"。

---

## 1. 五类补全（逐项检查）

### 1.1 集首衔接

**问题**：前集结尾有个动作，本集开头若原样重复，会显得拖沓；若完全不提，观众又接不上。

**规则**：以"动作已完成、人物已在场景中"的状态开场，用一句台词/一个动作自然回扣前情。

**实例**（第57集）：
- 56集尾：林玄怀抱红孩儿跃向半空。
- 57集首：**不重复**该动作，直接以"四人已在云海疾驰"大全景开场，朱罡烈一句"咱们刚从芭蕉洞出来，不往古神宫走，怎么来了东海？"自然回扣前情、抛出本集矛盾。

### 1.2 场景跳跃补桥接

**问题**：剧本从 A 场景直接跳 B 场景，中间缺"入/出"过渡，且未交代同行人物的去向。

**规则**：新增一个短桥接段，完成空间过渡，并把所有在场人物的站位/去向交代清楚。

**实例**（第57集 v2 新增段落03「入龙宫桥接」）：
- 剧本原文：四人"扎进海面" → 直接跳到"林玄把禁制球扔向敖广"。
- 缺失：① 怎么从海面进到龙宫正殿的；② 57-2 为什么只写了林玄和敖广，秦渊/朱罡烈/金蝉子三人去哪了。
- 补全：新增 12 秒桥接段——四人自海面水幕穿出、落入水晶宫正殿，林玄上前与敖广对峙，秦渊/朱罡烈/金蝉子退居殿门两侧后景。**同时解释了 57-2 未列三名同伴的去向**（仍在场、沉默、不动嘴）。

### 1.3 台词拆段

**问题**：单句长台词写在一行，但口型镜头有 ≤4 秒的限制，撑不下整句。

**规则**：把同一句台词拆成两段——前段镜头收到"半句"结束，后段镜头从"下半句"接起，跨段连续。

**实例**（第57集 v2）：
- 林玄台词原文："火焰山是旧秩序在陆地上的吸能点。龙宫则是他们输送本源能量的管道。"
- 拆段：段落01 结尾收"火焰山是旧秩序在陆地上的吸能点。"；段落02 开头接"龙宫则是他们输送本源能量的管道。"（同一句话拆两段，避免单口型镜头过长）。

### 1.4 未出场人物去向

**问题**：逻辑上应在场，但剧本某场只列了部分人物，导致观众疑惑"其他人呢"。

**规则**：处理为"后景沉默群像"——不新增、不删台词，只交代其站位与"沉默不动嘴"状态。

**实例**（第57集 v2）：
- 57-2/57-3 剧本未列秦渊/朱罡烈/金蝉子，但 57-1 四人一同入海。
- 补全：三人"退居两侧后景、沉默群像，仅在建立/反打时带出，对峙特写不取"。

### 1.5 情绪外化动作

**问题**：心理状态只有台词，没有可见动作，画面表现力弱。

**规则**：给心理状态一个物理动作，用"失控的肢体"外化内心。

**实例**（第57集）：
- "真相击穿防御" → 敖广猛地冲下台阶、**碰翻酒樽、酒水洒一地**（用酒水洒地的失控动作外化）。
- "旧秩序不可言说的压迫" → 龟丞相**跪地磕头**（用恐惧反衬压迫）。
- "全员被震" → 三龙虚影化形、三位龙王**接连后退**（用人数递增 + 后退外化）。

---

## 2. 补全边界（不可逾越）

- **只补"过渡与逻辑"**：集首、桥接、拆段、人物去向、情绪动作，都属于"让画面连得上"的范畴。
- **不增删人物**：补桥接只能"交代已有角色去向"，不能凭空加人。
- **不改台词**：拆段是"把原台词切成两半"，不增字、不减字、不改字。
- **不改剧情**：补全不能改变因果、不能提前泄露后续伏笔、不能改变人物关系。
- **显式标注**：每条补全必须写清"本版补全/本版新增"，便于用户一眼看出你动了哪里、随时回退。

---

## 3. 补全的可执行落地格式

补全不能写成"这里要过渡一下"，必须落成可拍的指令：

```text
【本版补全】段落03｜入龙宫桥接（12秒）
- 补全目的：剧本"入海"到"扔禁制球"之间缺入殿过渡；同时交代秦渊/朱罡烈/金蝉子去向。
- 画面：四人自海面水幕穿出、落入水晶宫正殿入口；林玄稳步上前，三人左右分立停下退居后景；林玄停在殿中抬眼望向高台敖广。
- 站位：林玄画面左前（访客位，看向右），敖广画面右高台龙案后（主人位，看向左），三人左后侧陪位沉默。
- 音效：水声、海水涟漪、脚步、殿内回响。
- 台词：全程无台词、无人张嘴。
```

## 4. 输出前自检清单

- [ ] 集首是否避免重复前集动作、有无自然回扣前情。
- [ ] 每个场景切换是否检查了"入/出"过渡，缺口是否已补桥接。
- [ ] 长台词是否已拆段，单口型镜头是否 ≤4 秒。
- [ ] 每个"逻辑上应在场但剧本未列"的人物，是否交代了去向（后景沉默/殿外/离场）。
- [ ] 强烈的心理状态是否配了可见的物理动作。
- [ ] 每条补全是否标注"本版补全"，且未增删人物、未改台词、未改剧情。
