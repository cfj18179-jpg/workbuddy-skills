# 01 · 剧本剖析与节奏点设计

上半部分：剧本深度剖析（五维）。下半部分：每集节奏点设计 + 节奏校验。

---

## 上：剧本深度剖析（五维）

通读全剧后依次完成五个维度，每个维度都要给出**证据**（引用具体集数/场次/台词），禁止空泛定性。

### 维度一：类型与题材定位

- 判定男频/女频、题材类型（战神归来/赘婿逆袭/甜宠/复仇/穿越/重生/马甲/豪门/穿越年代…）。
- 类型决定**爽点类型库**，例如：
  - 战神/逆袭类：打脸、身份揭露、地位碾压、旧敌俯首
  - 甜宠类：心动瞬间、占有欲、误会解除、双向奔赴确认
  - 复仇类：隐忍蓄力、证据到手、当众揭露、反杀
  - 悬疑类：线索浮现、排除嫌疑、真相反转
- 写明「本剧观众为什么付费/追更」一句话。

### 维度二：冲突结构

- **主线冲突**：一句话说清（谁 vs 谁，争什么，阻碍是什么）。
- **每集冲突**：每集必须有一个当集可感知的小冲突，且服务于主线。
- **冲突升级链**：逐集检查冲突烈度是否递增（赌注变大/对手变强/代价变重）。若发现连续两集冲突烈度持平或下降 → 标记为节奏隐患，列入风险提示。

### 维度三：人物弧线

- 主角：起点状态（弱/被误解/被压制）→ 终点状态（强/被认可/掌控）。
- 关键转折点：列出发生反转的具体集数。
- 反派/对手：压制力的来源，何时被反制。
- 弧线不是匀速的——必须落在具体集的节奏点上。

### 维度四：爽点分布盘点

- 全剧爽点清单：逐集列出爽点（类型+内容+位置）。
- 画成「爽点地图」：集数 × 爽点密度。若某集零爽点 → 标红（短剧不允许零爽点集）。
- 检查爽点**前置**：前 3 集必须至少有一次高强度爽点，否则观众流失。

### 维度五：钩子链盘点

- 逐集列出集尾钩子，检查是否环环相扣：上一集钩子 → 下一集开场是否承接。
- 钩子强度分级：S（危机/身份揭露前一秒/重大反转）、A（新悬念/新对手）、B（情绪未落）、C（平淡收尾，**不合格，必须改**）。

### 剖析产出：「全剧导演理解」一页纸

```
【类型基调】男频逆袭 × 年代赶海，付费点＝身份反差打脸
【主线冲突】……（一句话）
【情绪总曲线】压（1-8集）→ 首爆（9集）→ 假性回落 → 总爆发（大结局）
【爽点地图】1集×2｜2集×1｜3集×3｜…（零爽点集标红）
【钩子链】1集尾：…（S）→ 2集头承接 ✓｜…（C 级标红并给改法）
【节奏隐患】冲突持平段、零爽点集、慢热开场
```

## 下：每集节奏点设计

### 七类节奏点

| 类型 | 作用 | 情绪值参考 |
|---|---|---|
| 开场钩子 | 0-5 秒抓住观众，承接上集或直入冲突 | -2 ~ ±0 |
| 悬念点 | 埋钩，制造期待 | -1 ~ +1 |
| 压制点 | 情绪下压，为爆发蓄力 | -3 ~ -5 |
| 爽点 | 情绪上扬峰值，观众「爽到了」 | +3 ~ +4 |
| 反转点 | 信息颠覆，认知重组 | ±急变 |
| 情绪爆点 | 当集最大峰值 | +5 |
| 集尾钩子 | 驱动下一集的悬念 | 悬置 |

### 90 秒基准节拍骨架

| 时间轴 | 段落功能 | 节奏要求 |
|---|---|---|
| 0-5s | 开场钩子：承接上集钩子或本集冲突直入 | 必须有钩子，禁止慢热铺垫 |
| 5-20s | 建置 + 压制 | 交代场景/状态，同时埋下悬念点 |
| 20-35s | 第一个小节拍 | 小爽点或小反转（第一次「回报」） |
| 35-55s | 推进 + 压制升级 | 冲突烈度抬升，压制加深 |
| 55-70s | 情绪爆点 | 当集最大爽点/爆发，情绪 +5 |
| 70-85s | 余波 + 新悬念 | 爆发后的反应 + 埋下一个钩子 |
| 85-90s | 集尾钩子 | S/A 级钩子收尾 |

- **集时长以剧本声明为准**：剧本自带时长标注（如"每集 2 分钟"）优先于 90 秒默认值，节拍骨架按比例缩放，但三条铁律不变：**前 5 秒钩子、每 10-15 秒一个节奏事件、集尾钩子**（时间轴 0-5s 钩子段在任何时长下均不缩放）。
- 情绪曲线必须呈「压→爆」循环：短剧忌讳一路平（无聊）也忌讳一路爆（疲劳、脱敏）。

### 节奏点落地规则

1. **可视证据**：每个节奏点必须落到具体台词/动作/画面（如「第 7 集爆点：陈康把地契拍在村长脸上，台词『这地，姓陈了』」）。禁止只写「此处情绪爆发」。
2. **每集节奏点表**格式：

```
第 N 集（90s）｜集冲突：……
| 时间轴 | 节奏点 | 类型 | 内容与可视证据 | 情绪值 |
| 0-5s | 承接上集钩子 | 开场钩子 | ……（台词/动作） | -2 |
| ……
| 85-90s | 集尾钩子 | 钩子 | …… | 悬置 |
本集情绪曲线：-2 → -4 → +2 → -3 → +5 → +1 → 悬置
```

3. **节奏事件判定**：一个「因→果」的完整小闭环（小悬念抛出→回应 / 小压制→小反击）才算一个节奏事件；纯过渡画面不算。

### 节奏校验清单（每集必过）

- [ ] 前 5 秒有钩子？
- [ ] 是否存在 >15 秒无节奏事件的段落？（有 → 拆入悬念点或压缩该段）
- [ ] 集尾有钩子？强度 S/A？（C 级必须回改）
- [ ] 情绪曲线是「压→爆」循环？峰值只有一处 +5？
- [ ] 爽点前置？（当集第一个爽点不晚于 35s）
- [ ] 台词估时不超载？语速公式：高强度 4.5-6 字/秒、中 3.2-4 字/秒、低 2.8-3.5 字/秒；口型镜头单条 ≤4 秒。台词总时长超过全集时长 60% 即视为超载 → 提示删改（**须交付原版+优化版两版，不得单方面删**）。

### 大纲/不完整剧本的节奏点处理

- 只有大纲：先按五维剖析大纲（信息可能不全，标注「待剧本确认」），给**全剧节奏框架**（每集钩子链 + 爽点分布规划），用户确认后再细化单集。
- 只有前几集剧本 + 后续大纲：已写集走全流程；未写集给节奏点**框架占位表**（时间轴 + 建议节奏点类型 + 待填内容），不虚构具体台词。
