# 04 · 提示词写法铁律

本文件整合所有既定约定，与 SKILL.md 的流程配合使用。违反任何一条即为违约交付。

## 一、台词铁律（最高优先级）

1. **一字不差**：台词必须按剧本完整呈现，严禁省略号缩写、漏写、擅自删改——哪怕是很长的 OS/旁白也要写全。
2. **两版交付**：若认为剧情或台词不合理、需要省略/修改时，**必须交付两版**——「严格按剧本的原版」+「省略/修改后的优化版」，明确标注差异，让用户选择。不得只给一版。
3. 未经用户确认，不得单方面删改剧本内容。

## 二、节奏与镜头标准

1. 每集时长控制在**一分半（约 90 秒）左右**；其他时长按比例缩放节拍骨架。
2. 镜头**多、碎、快**：每集约 25-35 个镜头，平均 3 秒/镜。
3. **声画分离**：人物说话时，画面不全程给说话本人——根据剧情切听话者反应、环境空镜、相关道具特写、其他在场人物反应；只有**开口瞬间**给说话者，随后切走。
4. 台词节奏快、镜头切换密，不拖沓。
5. 口型镜头单条 ≤4 秒；OS/旁白不张嘴。

## 三、语速估时

| 情绪强度 | 字/秒 |
|---|---|
| 高强度（争吵/爆发） | 4.5-6 |
| 中等（日常对话） | 3.2-4 |
| 低（沉郁/耳语） | 2.8-3.5 |

台词总时长超过全集时长 60% 视为超载 → 触发两版交付规则。

## 四、写法禁令

1. **禁空词**：电影感、高级感、3D 风格、大片质感等虚词一律不写；用具体可生成的画面语言替代。
2. **光必有物理来源**：写清光源（窗光/灯泡/火光/月光）与方向。
3. **默认硬切**：不生成转场特效——叠化、淡化、闪白、划像一律禁止。
4. **默认真人写实**风格；写实际质感与光影，不写风格标签堆砌。
5. 动作按真人行为链拆解：起始 → 预备 → 主动作 → 联动 → 重心 → 接触反馈 → 下意识反应 → 情绪落点 → 动态切口。

## 五、连续性

1. 多人戏首镜严格建立：人数、站位、朝向、空间锚点、轴线，写成**可见的屏幕方向指令**。
2. 动态衔接优先：动作切出 / 视线切点 / 遮挡切口；避免静止帧接静止帧。
3. 相邻镜头若出现「因→果」缺过程（能量/动作/状态/位移瞬移），补 1-3 秒过程镜头（因果链补全，参考 knee-li-one）。
4. 明确参考素材控制对象：哪张图锁哪个角色/场景/道具，哪条音频锁谁的声线口型。

## 六、身份与形象

1. 角色外形锚点（发色/瞳色/脸型/体型/肤质）在跨镜头提示词中保持一致复述，不依赖观众记忆。
2. 剧情性受伤、换装、技能特效**只在分镜·视频层实现**，不动资产卡（联动全资产大师/短剧服化方案的产出）。
3. 主角面容默认干净清爽（无胡茬/痘印/油光）；皮肤保留真实质感（毛孔/自然色差），不磨皮不瓷肌。

## 七、输出前自查清单

- [ ] 台词逐句比对剧本，一字不差？（需删改处已给两版？）
- [ ] 每个镜头有明确时长且合计 ≈ 集时长？
- [ ] 声画分离执行了？（说话者画面不全程）
- [ ] 有无空词/无源光/转场特效漏网？
- [ ] 跨镜头身份锚点一致？
- [ ] 提示词长度在安全区（英文 ~95 词 / 中文 ~280 字）？
- [ ] 目标模型适配壳正确（时长切分/身份锁定/音频标注/负面约束）？
