# 02 · 输入形态分流

收到任务后先识别输入形态，按下表路由。识别原则：看用户给的是什么（整剧/单集/大纲/分镜表/片段），而不是看用户怎么称呼它。

## 六种形态的路由细则

### 形态 A：完整整剧 / 多集剧本

- 走全流程：剖析（第3步）→ 节奏点（第4步）→ 校验（第5步）→ 分镜（第6步）→ 提示词（第7步）。
- 集数多时先交付「全剧导演理解 + 全部集的节奏点表」，等用户确认节奏后再逐集出分镜与提示词（避免节奏返工导致分镜白做）。

### 形态 B：单集剧本

- 先索取全剧剧本或前后集剧情（一句话梗概亦可），用于：钩子链承接判断、人物状态连续性。
- 用户拒给 → 按片段模式处理，**显著标注**「结论仅基于本集，钩子承接与人物连续性未经全剧校验」。

### 形态 C：剧情大纲 / 梗概

- **先扩写，后设计**，两段式：
  1. 把大纲按集拆成「场次大纲」（每集：场景、人物、事件、钩子），交付给用户确认——扩写有创作成分，未经确认不得直接进分镜。
  2. 确认后走全流程。
- 扩写原则：只补过渡与逻辑，不新增主线人物、不改大纲既定事件；扩写内容用「扩」标注，方便用户删改。

### 形态 D：不完整剧本（只有大纲 + 第一、二集等）

- 已写成剧本的集 → 按形态 A 全流程。
- 只有大纲的集 → 产出**节奏点框架占位表**（时间轴 + 建议节奏点类型 + 建议钩子，内容栏留「待剧本」），不虚构台词与具体画面。
- 交付时提醒用户：后续集剧本到位后，占位表可无缝替换为完整节奏点表。

### 形态 E：已有分镜表

- 跳过剖析与分镜设计，做两件事：
  1. **节奏校验**：把分镜表按时间轴还原，套用 `01-剧本剖析与节奏点设计.md` 的校验清单逐项检查，输出「节奏体检报告」（钩子/节拍密度/情绪曲线/爽点前置四项），不合格处给修改建议（只建议，不改原表）。
  2. **提示词转译**：按第 7 步把每个镜头转成核心层+适配壳提示词。
- 若分镜表台词与所给剧本台词不一致 → 停下报告差异，等用户裁决，不得默认以分镜表为准。

### 形态 F：单场戏 / 片段

- 快速模式，不问全剧参数，只确认目标模型与风格。
- 做**片段内微节奏**：把片段时长按比例套节拍骨架（例：30 秒片段 = 钩子 → 小压制 → 小爆点 → 悬置），25-35 镜密度换算到片段时长。
- 台词一字不差铁律同样适用。

## 分流决策速查

```
用户给了什么？
├─ 多集剧本 ……………………………… A 全流程（先节奏后分镜）
├─ 单集剧本 ……………………………… B 索上下文→A 或片段模式
├─ 大纲/梗概 …………………………… C 扩写→确认→A
├─ 大纲+部分集 ………………………… D 混合：A + 占位表
├─ 分镜表 ……………………………… E 节奏体检 + 转译
└─ 一场戏/片段 ………………………… F 快速模式
```

## 通用规则

- 无论哪种形态，**台词一字不差**铁律不变（详见 `04-提示词写法铁律.md`）。
- 任何形态下发现剧情逻辑漏洞，先报告、给修补建议，未经确认不擅自改。
