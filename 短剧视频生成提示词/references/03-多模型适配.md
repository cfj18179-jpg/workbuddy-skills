# 03 · 多模型适配（核心层 + 适配壳）

## 设计原则

**一个分镜只写一次「核心层」，多模型交付时只换「适配壳」，不重写核心。**

- **核心层**（模型无关）：主体 + 动作（真人行为链）+ 景别运镜 + 情绪 + 光线（有物理来源）。写清楚「观众看到什么」，不写任何模型参数。
- **适配壳**（按目标模型）：时长切分、比例、身份锁定方式、音频处理、镜头术语映射、负面约束。壳由核心层机械变换而来。

## 各模型适配要点

> ⚠️ 视频模型参数迭代快，以下为适配框架与已知要点；**每次交付前，若对当前版本的时长上限/模式/参数不确定，先向用户确认其所用版本与入口**，不要凭旧参数硬写。

### Seedance 2.5（即梦）

- 画幅按用户指定（海外短剧常为竖屏 9:16；技能默认值不再假定 16:9）；**单条时长上限 U 以用户当前版本为准（Seedance 2.5 现为 0-29 秒）**，**段落式**生成（一条可含多镜号与硬切），不机械一镜一条。
- 身份锁定：**图生视频（i2v）**——每条标注用哪张资产图锁哪个角色/场景/道具。
- 声线口型：**参考音频**——标注哪条音频锁谁的声音；口型镜头单条 ≤4 秒。
- 台词语速估时：高强度 4.5-6 字/秒、中 3.2-4、低 2.8-3.5。
- OS/旁白不张嘴；默认硬切、不生成转场特效（叠化/淡化/闪白/划像一律禁）。

#### ⚠️ 切条算法（**上限是上限，不是目标段长**）

事故教训：曾把「单条上限 28 秒」误当成「目标段长」，把 1-1 场 26 秒硬拆成 13+13 两条；切完又没回头做合并检查，凭空多出 3 条。**照下面五步走，不得凭手感切。**

1. **取上限 U**：问清用户当前版本的单条上限（Seedance 2.5 现为 29 秒）。**不确定先问，不硬写。**
2. **算下限**：`条数下限 = ⌈总时长 ÷ U⌉`（120s ÷ 29s → 5 条）。这是**下限**，实际条数应尽量贴近它。
3. **定切点优先级**：
   ① **场次/影调/轴线边界**（一条内**只能有一个 `{风格子类}`**，绝不跨场次）；
   ② **节奏断点**（爆点之后、闪回进出、场景转场）；③ 最后才按时间硬切。
4. **合并检查（强制，最容易漏）**：切完后**逐对扫描相邻条**——若「同场次 + 同影调 + 同轴线」且**合计 ≤ U**，**必须合并**。合并后条内镜头时码**从 0 重新起算**。
5. **过碎判定**：若最终条数 ≥ 下限 + 2，视为**切条过碎**，必须逐条复核为何不能再并。

**必须跑脚本验收**：
```
python scripts/segment_check.py --file 提示词.md --limit 29 --expected-total 120 --report 审查-切条.md
```
退出码 0 = 通过（无超限、无残余可合并对、总时长一致）。**判定 ❌ 不得交付。**
（`--plan shots.txt` 可反向规划：输入「镜号 时长 场次」清单，输出最优切条方案。）

#### ⚠️ 固定前置条件（**每条必带，漏写即为不合格交付**）

> **另一条同等级的硬约束**：**台词必须内嵌在镜头行内**（`※台词：角色（口型/画外/群杂，时长）："原文"`），
> 并标注发声方式与时长；**只把台词写在文末核对表里＝台词全丢**——核对表给人看，代码块正文才是给模型吃的。
> 交付前必跑 `scripts/script_audit.py` 做双指标核对，判定 ✅ 才可交付（详见 `05-剧本一致性审查机制.md`）。

实操层交付**不是**普通的"参考图 + 描述"块，而是 knee-li-one 的「分镜时序」喂入格式。**每条必须严格套用以下骨架**（用户独门，缺一不可）：

```
分镜时序N
要求：画面中不出现字幕，真人写实实拍质感（非动画、非 3D 渲染），{风格子类}；
      人物表情自然、动作自然，镜头中的人物动作自然；
      主体说话时，镜头中出现的背景人物看向说话主体（未出现的不强加入镜）。
素材定义：
@素材名 是 定义（角色/场景/道具；多状态角色与道具附加状态需分别声明）
角色音频参考@声音名
- 光影：<真实布光，写清光源与方向>
位置／轴线母版：<站位、朝向、谁面向谁、画面左右>
附加：<关系图用途限定 + 大小对比 + 明示不做首帧等>
镜头1：<电影语言镜头：景别+运镜+动作链>
镜头2：…
要求/注意：<收尾约束，必须覆盖：人数上限、状态保持、道具唯一与大小、站位不改、
          表演自然、看向主体、画面无字幕水印 Logo、默认硬切不出转场特效>
```

**固定收尾段落（建议原样保留）：**

> 要求/注意：出现的参考素材人物严格按声明人数出现，不多出现；道具唯一且大小合理；人物状态一旦切换即保持、不反复跳；带到位置关系的人物不因镜头关系强行转向、保持原站位；画面中不出现字幕、水印、Logo；默认硬切，不生成转场特效（叠化/淡化/闪白/划像）。

**八条用户独门约束（收尾行必须覆盖）：** ①无字幕 ②表演自然 ③背景人物看向说话主体（不强加入镜）④严格人数上限 ⑤状态切换后锁死 ⑥道具唯一且大小合理 ⑦关系镜配角站位不改 ⑧关系图/站位图声明「不做单帧/首帧参考，不参考该图质感」。

**其他格式要点：**
- 镜头描述前必须先给**素材定义块 + 站位轴线**，让模型先"认得人、站好位"，再"动起来"。
- 跨镜衔接用「**承接上一个镜头**」；画外音用「**继续伴随…画外音**」并标注不张嘴。
- 焦点转换必须**绑定到动作/台词节点**（"当…的时候"），不写无依据的变焦。
- 转场特效（如黑屏）要写清时长 + 期间的音效。
- 详见 `knee-li-one/references/实操提示词写法.md`。

### Wan（通义万相）

- 提示词对中文描述友好，可直接用中文核心层，不必先译英文。
- 支持**首尾帧**控制：跨镜头衔接优先「上条尾帧 = 下条首帧」或遮挡接缝帧。
- 适配时把核心层按该模型支持的时长切条（以当前官方时长上限为准）；无原生音频对齐能力时，台词一律标注「后期配音/对轨」，不在提示词里写口型同步要求。

### MiniMax（海螺 / Hailuo，H 系）

- 擅长响应**导演式镜头指令**：核心层中的景别运镜改写为该模型的镜头控制术语（推拉摇移跟甩、zoom in/out 等显式指令词，中英按入口要求）。
- 单条时长通常较短（6-10 秒量级，以当前版本为准）→ **逐镜或两镜一条**，比 Seedance 切得更碎；分镜表中的 3 秒/镜密度正好适配。
- 台词/音频能力以当前版本为准：无口型对齐时同样标注后期配音。

## 适配壳生成流程

1. 取核心层，确认时长 → 按目标模型时长上限切条（Seedance 段落式 / 短时长模型逐镜）。
2. 身份锁定：有资产图 → 写参考图对应关系；无 → 提示词内强化角色外形锚点描述（发色/五官结构/服装），并提醒用户跨条一致性风险。
3. 音频：按模型能力写「参考音频锁声线」或「后期配音」标注。
4. 镜头术语映射：景别运镜按模型偏好改写（如 45 度俯拍 → high-angle oblique view；中英按入口）。
5. 附加该模型的负面约束清单。
6. **长度控制**：生图/视频工具对提示词长度敏感，单条提示词过长的报警阈值各家不一——英文参考 ~95 词、中文参考 ~280 字以内为安全区；超长先压缩修饰词，不砍动作与因果。

## 负面约束清单（通用基底，按模型增删）

- 形变：五官畸变、手指异常、肢体多余/缺失、面部崩坏
- 身份：角色脸变化、串脸
- 字幕/水印/Logo、UI 元素
- 转场特效（叠化/淡化/闪白/划像）
- 风格漂移：动画化、油画化、3D 渲染化（默认真人写实时）
- 时空错乱：服装瞬间变化、道具瞬移、场景跳变

## 多模型交付格式

```
【镜 07｜3s｜节奏点：爽点｜核心层】
陈康（30岁，晒黑小麦色，黑色高领毛衣）将地契拍在桌面上，
纸页震起又落下；中景，镜头随拍桌动作轻微下压；
他下颌绷紧、眼神钉住村长；窗外午后侧光打亮半张脸。

【适配：Seedance 2.5】
（并入段落 03，i2v 锁陈康资产卡 01；台词「这地，姓陈了」口型 1.5s ≤4s；
 负面约束见总表）

【适配：Wan】
（中文核心层直用；尾帧 = 镜 08 首帧；台词后期配音）

【适配：MiniMax】
（单镜一条，6s 上限内；镜头指令：medium shot, slight push-in；
 台词后期配音）
```
