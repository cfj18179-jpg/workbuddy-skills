# 03 · 多模型适配（核心层 + 适配壳）

## 设计原则

**一个分镜只写一次「核心层」，多模型交付时只换「适配壳」，不重写核心。**

- **核心层**（模型无关）：主体 + 动作（真人行为链）+ 景别运镜 + 情绪 + 光线（有物理来源）。写清楚「观众看到什么」，不写任何模型参数。
- **适配壳**（按目标模型）：时长切分、比例、身份锁定方式、音频处理、镜头术语映射、负面约束。壳由核心层机械变换而来。

## 各模型适配要点

> ⚠️ 视频模型参数迭代快，以下为适配框架与已知要点；**每次交付前，若对当前版本的时长上限/模式/参数不确定，先向用户确认其所用版本与入口**，不要凭旧参数硬写。

### Seedance 2.5（即梦）

- 画幅 16:9 横屏；单条时长 ≤28 秒，**段落式**生成（一条可含多镜号与硬切），不机械一镜一条。
- 身份锁定：**图生视频（i2v）**——每条标注用哪张资产图锁哪个角色/场景/道具。
- 声线口型：**参考音频**——标注哪条音频锁谁的声音；口型镜头单条 ≤4 秒。
- 台词语速估时：高强度 4.5-6 字/秒、中 3.2-4、低 2.8-3.5。
- OS/旁白不张嘴；默认硬切、不生成转场特效（叠化/淡化/闪白/划像一律禁）。
- 遵循 knee-li-one 的实操喂入格式（分镜时序 + 参考素材对应 + 负面约束）。

### Wan（通义万相）

- 提示词对中文描述友好，可直接用中文核心层，不必先译英文。
- 支持**首尾帧**控制：跨镜头衔接优先「上条尾帧 = 下条首帧」或遮挡接缝帧。
- 适配时把核心层按该模型支持的时长切条（以当前官方时长上限为准）；无原生音频对齐能力时，台词一律标注「后期配音/对轨」，不在提示词里写口型同步要求。

### MiniMax（海螺 / Hailuo，H 系）

- 擅长响应**导演式镜头指令**：核心层中的景别运镜改写为该模型的镜头控制术语（推拉摇移跟甩、zoom in/out 等显式指令词，中英按入口要求）。
- 单条时长通常较短（6-10 秒量级，以当前版本为准）→ **逐镜或两镜一条**，比 Seedance 切得更碎；分镜表中的 3 秒/镜密度正好适配。
- 台词/音频能力以当前版本为准：无口型对齐时同样标注后期配音。

## 适配壳生成流程

1. 取核心层，确认时长 → 按目标模型时长上限切条（Seedance 段落式 / 短时长模型逐镜）。
2. 身份锁定：有资产图 → 写参考图对应关系；无 → 提示词内强化角色外形锚点描述（发色/五官结构/服装），并提醒用户跨条一致性风险。
3. 音频：按模型能力写「参考音频锁声线」或「后期配音」标注。
4. 镜头术语映射：景别运镜按模型偏好改写（如 45 度俯拍 → high-angle oblique view；中英按入口）。
5. 附加该模型的负面约束清单。
6. **长度控制**：生图/视频工具对提示词长度敏感，单条提示词过长的报警阈值各家不一——英文参考 ~95 词、中文参考 ~280 字以内为安全区；超长先压缩修饰词，不砍动作与因果。

## 负面约束清单（通用基底，按模型增删）

- 形变：五官畸变、手指异常、肢体多余/缺失、面部崩坏
- 身份：角色脸变化、串脸
- 字幕/水印/Logo、UI 元素
- 转场特效（叠化/淡化/闪白/划像）
- 风格漂移：动画化、油画化、3D 渲染化（默认真人写实时）
- 时空错乱：服装瞬间变化、道具瞬移、场景跳变

## 多模型交付格式

```
【镜 07｜3s｜节奏点：爽点｜核心层】
陈康（30岁，晒黑小麦色，黑色高领毛衣）将地契拍在桌面上，
纸页震起又落下；中景，镜头随拍桌动作轻微下压；
他下颌绷紧、眼神钉住村长；窗外午后侧光打亮半张脸。

【适配：Seedance 2.5】
（并入段落 03，i2v 锁陈康资产卡 01；台词「这地，姓陈了」口型 1.5s ≤4s；
 负面约束见总表）

【适配：Wan】
（中文核心层直用；尾帧 = 镜 08 首帧；台词后期配音）

【适配：MiniMax】
（单镜一条，6s 上限内；镜头指令：medium shot, slight push-in；
 台词后期配音）
```
