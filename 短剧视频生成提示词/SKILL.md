# 短剧视频生成提示词（剧本剖析 · 节奏点 · 多模型）

## 定位

对短剧剧本做**深度剖析**，为**每集设计节奏点**并**严格把控短剧节奏**，再由节奏点驱动分镜，最终转译为**多款视频模型**可执行的提示词。核心信念：短剧的生死在节奏——观众 5 秒内决定划走与否，每 10-15 秒必须给一次「留下来」的理由。

与其他技能的分工：

| 能力 | 本技能 | 其他技能 |
|---|---|---|
| 剧本五维深度剖析 + 每集节奏点设计 | ✅ 核心 | knee-li-one 仅场次功能判断 |
| 节奏校验（钩子/节拍密度/情绪曲线） | ✅ 核心 | 无 |
| 六种输入形态分流（含不完整剧本/大纲扩写） | ✅ | knee-li-one 只认完整剧本 |
| 多模型提示词（Wan / MiniMax H3 等） | ✅ | knee-li-one 仅 Seedance 2.5 |
| 镜头级因果链补全、一镜到底遮挡接缝 | 借用 | knee-li-one |
| 角色资产卡 / 服化方案 | 联动 | 全资产大师 / 短剧服化方案 |

## 第 1 步：输入形态识别与分流

先判断输入属于哪种形态，再决定流程入口。**加载 `references/02-输入形态分流.md`** 执行路由：

| 输入形态 | 流程入口 |
|---|---|
| 完整整剧/多集剧本 | 全流程（第 2 步起） |
| 单集剧本 | 全流程，但先索取全剧上下文；拒给则按片段模式并标注 |
| 剧情大纲/梗概 | 先扩写成场次大纲（需用户确认），再进全流程 |
| 不完整剧本（只有大纲+第一二集） | 已写集走全流程；未写集只给节奏点框架占位 |
| 已有分镜表 | 跳过剖析与分镜设计，直接做节奏校验 + 提示词转译 |
| 单场戏/片段 | 快速模式：片段内微节奏 + 提示词 |

## 第 2 步：制作参数问询（一次性问全，不反复追问）

只问仍缺失的关键项：目标模型（Seedance 2.5 / Wan / MiniMax H3 / 其他）、画幅与平台、风格子类、参考素材（资产卡/音频）、单集时长（默认 90 秒）、硬性要求。已知信息不得重复询问。

## 第 3 步：剧本深度剖析（五维）

**加载 `references/01-剧本剖析与节奏点设计.md`**，依次完成：

1. **类型与题材定位**：男频/女频、题材类型 → 决定爽点类型库。
2. **冲突结构**：主线冲突、每集冲突、冲突升级链。
3. **人物弧线**：主角起点状态→终点状态、关键转折点。
4. **爽点分布盘点**：全剧爽点清单（打脸/逆袭/获得/揭露/反杀）及其位置。
5. **钩子链盘点**：逐集尾钩子，检查是否环环相扣成链。

产出「全剧导演理解」一页纸：类型基调、主线冲突、情绪总曲线、爽点地图、钩子链。

## 第 4 步：每集节奏点设计（核心）

**按 `references/01-剧本剖析与节奏点设计.md` 下半部分执行**，为每一集产出「节奏点表」：

- 以 90 秒为基准的时间轴节拍骨架（0-5s 钩子 → 5-20s 建置压制 → 20-35s 小节拍 → 35-55s 推进升级 → 55-70s 情绪爆点 → 70-85s 余波新悬念 → 85-90s 集尾钩子）。
- 七类节奏点（开场钩子/悬念点/压制点/爽点/反转点/情绪爆点/集尾钩子）逐点落到**可视证据**（具体台词/动作/画面），禁止只写抽象情绪。
- 每个节奏事件标注情绪值（-5 压抑 ~ +5 爆发），形成该集情绪曲线。
- 若时长不是 90 秒，按比例缩放节拍骨架，但「前 5 秒钩子、每 10-15 秒一个节奏事件、集尾钩子」三条铁律不变。

## 第 5 步：节奏校验（关卡）

对每张节奏点表执行校验清单，不合格必须回改节奏点而非硬往下走：

- 前 5 秒有钩子？是否存在 >15 秒无节奏事件的段落？
- 集尾有钩子？钩子强度是否足以驱动下一集？
- 情绪曲线是「压→爆」循环，而非一路平或一路爆？
- 爽点前置了吗（短剧观众耐心极短）？
- 台词总量估时是否超载（按语速公式估算，超载则提示删改——删改须遵守两版交付铁律）？

## 第 6 步：节奏点驱动分镜

- 镜数随时长换算，保持 **3-4 秒/镜**的密度：90 秒集 ≈ 25-35 镜（基准）；120 秒集 ≈ 30-40 镜；180 秒集 ≈ 45-60 镜。**先确认剧本声明的集时长，再定镜数**，不要机械套用 25-35 镜。
- 镜头「多、碎、快」的密度要求不随时长放宽：时段越长，越要靠碎镜头维持节奏。
- 每个节奏点分配 1-3 个镜头；节奏点之间的过渡用短镜头快速带过。
- 多人戏首镜建立人数、站位、朝向、空间锚点与轴线。
- 动态衔接优先动作切出/视线切点/遮挡切口，避免静帧接静帧。
- 若该集含跨镜因果（能量/动作/状态/位移的「瞬移」漏洞），按 knee-li-one 的因果链补全思路补 1-3 秒过程镜头。
- 台词**声画分离**：开口瞬间给说话者，随后切听话者反应/环境空镜/道具特写。

## 第 7 步：多模型提示词转译

**加载 `references/03-多模型适配.md` 与 `references/04-提示词写法铁律.md`**，两层结构输出：

- **核心层**（模型无关）：每个视频段落的镜头核心描述——主体+动作+景别运镜+情绪+光线。
- **适配壳**（按目标模型）：时长切分（Seedance ≤28s / 短时长模型逐镜）、身份锁定方式（i2v 参考图/首尾帧）、音频处理（参考音频/后期配音标注）、镜头术语映射、负面约束清单。

一个分镜只写一次核心层，多模型交付时只换壳不重写核心。

## 交付物结构

1. **全剧导演理解**（一页纸：类型基调/主线冲突/爽点地图/钩子链）
2. **每集节奏点表**（时间轴+节奏点类型+内容+可视证据+情绪值）——本技能的招牌交付物
3. **分镜表**（镜号/时长/节奏点归属/景别运镜/画面/台词/声音）
4. **多模型提示词**（核心层+适配壳，按所选模型出对应版本）
5. **风险提示**（需用户确认的删改项，两版并陈）

## 铁律速查（详见 references/04）

台词一字不差（省略即违约，需删改必交两版）｜集时长以剧本声明为准（默认90秒）｜镜数=时长÷3~4秒（90s集≈25-35镜、120s集≈30-40镜）｜口型镜头≤4秒｜声画分离｜禁空词（电影感/高级感/3D风格）｜光必有物理来源｜默认硬切不出转场特效｜默认真人写实。
