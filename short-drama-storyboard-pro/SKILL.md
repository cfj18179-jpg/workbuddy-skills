# 短剧分镜（Pro · 含剧本衔接合理性补全）

## Overview

这是 `short-drama-storyboard` 的升级版。它在保留原有「总导演 → 场次/分镜导演 → 视频提示词设计师」三层工作顺序与两道强制关卡的基础上，补上了两件旧版没做透的事：

1. **剧本衔接合理性补全**（本版核心新增）：剧本作者常在场景跳跃、人物调度上留白。本版要求在分镜阶段主动补全这些"过渡与逻辑"，让前后镜头衔接自然，同时**严守边界——只补过渡、不增删人物、不改台词、不改剧情**。
2. **Seedance 2.5 落地执行**：把"画幅 16:9、单条 ≤28 秒、图生视频首帧锁身份、参考音频锁声线、负面约束清单"等生成规格写进每一段提示词，产出可直接粘贴生成的文本。

核心价值：不机械配画，也不只停留在"导演分析"，而是用全剧导演视角控制剧情连续性，用"衔接补全"解决剧本留白，最终输出 Seedance 2.5 能稳定生成、前后连贯的段落式提示词。

## 触发与输入

当用户出现以下任一意图时使用本技能：

- "给这段剧本做分镜""对短剧剧本进行分镜设计"
- "帮我生成 Seedance / 即梦视频提示词"
- "剧本从 X 跳到 Y 中间没写清楚，帮我补一段过渡"
- 提供剧本文本（.txt / .md / .docx / 粘贴内容），可能附带角色图、场景图、道具图、配音 MP3、上一版关键帧/成片
- 要求"分镜合理、前后衔接自然、不新增人物、保留全部台词"等硬性约束

## 工作流程

按顺序执行，不得颠倒。

### 第 1 步：两道强制关卡（关卡一 → 关卡二）

- **关卡一（完整剧本导演关卡）**：默认必须先取得并阅读完整剧本再设计分镜。若用户只给当前场/单集/片段，先索取完整剧本，说明需要全剧判断基调、弧线、伏笔与场次功能；取得前不输出正式分镜。仅当用户明确说"绕过导演""只按当前片段直接做"时，才进入直接提示词模式，并标注结论仅基于当前片段。
- **关卡二（专业制作参数问询关卡）**：读剧本形成内部导演判断后，不得立即输出。先只询问仍缺失的关键参数：制作范围、视频比例与发布平台、视觉媒介与具体风格子类、参考素材及对应关系、生成规格（版本/时长/分辨率）、声音要求、硬性要求。不得重复询问已知信息，一次集中问询。用户答"导演决定"或授权跳过时，在输出开头列出参数假设。

信息不足时先输出问题，不输出分镜正文。

### 第 2 步：总导演设计

通读全剧，依次完成：

1. 完整阅读全剧，识别类型、核心冲突、人物弧线、反派升级路径、伏笔回收、集尾钩子、世界观与制作尺度。
2. 建立全剧导演基调卡（类型承诺、叙事基调、主观视角、表演尺度、镜头语法、视觉母题、节奏规则、规模曲线、风格禁区）。
3. 判断当前场次功能，每场只定一个第一表达重点、最多一个第二重点。
4. 提取可视证据（改变处境的动线、证明冲突的道具、关系变化的视线、身份能力的视觉证明等）。
5. 设计场次节奏（建立处境 → 触发 → 反应 → 冲突升级 → 揭示 → 反转/落点 → 钩子）。

### 第 3 步：剧本衔接合理性补全（本版核心新增）

加载 `references/衔接合理性补全.md`，按五类逐项检查并补全：

1. **集首衔接**：不重复前集结尾动作，以"已在场景中"的状态开场，用一句台词/动作自然回扣前情。
2. **场景跳跃补桥接**：剧本从 A 场景直接跳 B 场景、中间缺"入/出"过渡时，新增一个短桥接段，并交代所有在场人物的去向。
3. **台词拆段**：单句长台词跨两段——前段收半句、后段接半句，避免单口型镜头过长。
4. **未出场人物去向**：逻辑上应在场但剧本未列的人物，处理为"后景沉默群像"，不新增、不删台词。
5. **情绪外化动作**：给心理状态一个物理动作（碰翻酒樽＝失控、跪地磕头＝恐惧、后退＝错愕）。

**补全边界（不可逾越）**：只补"过渡与逻辑"，不增删人物、不改台词、不改剧情、不提前泄露后续集伏笔。每条补全都必须在输出中显式标注"本版新增/本版补全"，便于用户审阅回退。

### 第 4 步：分镜导演设计

- 以可生成的"视频段落"为单位（Seedance 2.5 单条 ≤28 秒，可含多镜号与硬切），不机械一镜一条。
- 每个镜号只有一个第一任务、最多一个第二任务。
- 动作按真人行为链拆解（起始 → 预备 → 主动作 → 联动 → 重心 → 接触反馈 → 下意识反应 → 情绪落点 → 动态切口）。
- 多人戏首镜建立严格人数、左右/前后站位、朝向、空间锚点与轴线；写成可见的屏幕方向指令（"A 固定在画面左、看向右侧 B"），而非空谈"180度轴线"。
- 动态衔接优先"动作切出/视线切点/遮挡切口"，避免静止帧接静止帧。

### 第 5 步：提示词设计师输出（Seedance 2.5）

- 继承导演基调与连续性，禁止"电影感/高级感/3D风格"空词。
- 明确参考素材控制对象：哪张图锁哪个角色/场景/道具，哪条音频锁谁的声线口型。
- 按情绪语速估算台词时长（高强度 4.5–6 字/秒、中 3.2–4、低 2.8–3.5），口型镜头 ≤4 秒，OS/旁白不张嘴。
- 设计真实布光（剧本场景 → 真实光源 → 情绪 → 强化 → 模型可执行描述），光必须有物理来源。
- 落实连续性与风险控制，输出常规负面约束，默认硬切、不生成转场特效。
- 产出分两层（按用户需要交付其一或两者）：
  - **设计层**：A–F 六段式分镜文档（A 全剧导演理解 → B 本次制作参数 → C 段落导演设计+衔接补全 → D 视频段落分镜表 → E 最终整合提示词 → 附：资产对应总表 & 风险提示）。
  - **实操层**：把设计层的一段拆成多条「分镜时序」，按 `references/实操提示词写法.md` 的喂入格式输出——每条以「要求：画面中不出现字幕…」开头，`@素材 是 定义` 声明图片、`音频参考@xxx` 声明音频，站位关系图显式标注「不做单帧/首帧参考」，镜头用电影语言（过肩/过道具前景关系拍、焦点转换绑定动作/台词节点、承接上一个镜头），结尾约束覆盖人数上限、状态保持、道具唯一与大小、站位不改、表演自然。

### 第 5.1 步：预告片 / 蒙太奇类任务的分组与字幕

预告片与常规单集分镜不同（跨十几个场景、平均 1.5–3 秒一镜），按以下规则处理：

- **分组规则**：实操层「一条 = 一个连续场景段落」，可含 2–3 个镜号（如 S01–S03 同场景）；**跨场景绝不合并**到同一条，否则模型会把两个场景糊在一起。因此预告片的实操条数通常多于 8–12 条，属正常，不必强行压缩。
- **时长校验**：每条累计时长不得超过生成版本单次上限（Seedance 2.5 为 28 秒）；预告片一般 15–20 条。
- **字幕卡**：无台词预告片的叙事由字幕卡承担，但**字幕卡不进提示词**——提示词统一锁「画面中不出现任何字幕、文字、水印」，字幕卡与剧名卡另出「时点表」（时点｜文本｜落点），由剪辑软件后期叠加。字幕卡文本优先取剧本原句，不改写。
- **无台词任务**：全部条目省略「音频参考@xxx」行，音效与配乐在结尾注明后期叠加。

### 第 6 步：输出前检查

- 导演检查：是否读完完整剧本、理解全剧弧线与当前场位置、每场单一重点、可视证据充分、未提前泄露后续剧情。
- 参数关卡检查：制作范围/比例/媒介/风格子类/素材/时长/声音/硬性要求是否确认。
- 衔接补全检查：五类衔接是否已检查；每条补全是否标注"本版补全"；是否守住"不增删人物、不改台词剧情"边界。
- 分镜与提示词检查：人数与画外方位、场景天气道具服装连续、新镜起点承接上镜结束状态、口型与 OS 规则、屏幕左右/视线/过肩归属、光源真实稳定、结尾有动态出口、负面约束齐全。

任一关键项不满足时先重新推理或向用户补问。

## 输出交付

- 设计层按六段结构交付，信息较少时可合并字段，但不得省略导演基调、制作参数、镜号时间轴和最终提示词。
- 实操层按「分镜时序」分条交付，每条一个生成任务，开头必带「画面中不出现字幕」、结尾必带人数/状态/道具/站位约束。
- 新增补全段落用「**本版补全**」标记，单独汇总在 C 段或附表中，方便用户一眼看出你改了哪里。
- E 段最终提示词以有效画面指令为主，不重复大段分析；每条开头统一「超写实…质感，16:9横屏，8K超精细，物理准确光照，参考图锁定…」，末尾统一「禁止变脸换装、人数增减、站位反转、道具漂浮、自动转场特效」。
- 若用户提供文件，可整理为 .md 分镜文档交付。

## 使用参考方法论

- 设计前先读取 `references/衔接合理性补全.md`（设计层的核心新增能力：五类衔接补全规则与实例）。
- 输出实操喂入文本前，先读取 `references/实操提示词写法.md`（实操层的 @素材引用语法、电影语言镜头、人数/状态/道具/站位约束）。
- 三层导演规则、两道关卡、输出前检查的完整版见旧 skill `short-drama-storyboard` 的 `references/director-methodology.md`；本版不重复展开，只做增量。

## 禁止事项

- 禁止在未取得完整剧本时默认进行导演设计（除非用户明确绕过）。
- 禁止在缺关键参数时猜测比例、媒介或风格。
- 禁止只按对白逐句配画、平均表现所有动作、擅自改剧情或重排用户给定镜号。
- 禁止补全时增删人物、改写台词、篡改剧情或提前泄露后续伏笔。
- 禁止把"衔接补全"写成抽象说明，必须落成具体画面/站位/运镜/台词。
- 禁止只输出理论而不交付可复制的最终提示词（除非处于剧本索取或参数问询阶段）。
- 禁止把站位关系图当作首帧/单帧参考（实操层必须显式标注「仅做站位参考」）。
- 禁止遗漏实操层的核心约束：画面无字幕、严格人数上限、角色状态保持、道具唯一与大小、站位不改、表演自然。
