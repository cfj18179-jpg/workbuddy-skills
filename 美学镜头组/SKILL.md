# 美学镜头组（单场景 · 无台词）

## 何时用 / 何时不用

**用**：用户给一张场景图（或描述）+ 一个情绪主题（震撼／敬畏／孤独／伤痛／暴怒／释然……）+ 时长，要「一组美学镜头」。没有剧本、没有台词、没有人物关系。

**不用**：有剧本、有台词、有剧情推进 → 转 `short-drama-storyboard-pro` / `knee-li-one`（那套要求完整剧本 + 两道关卡 + 台词声画分离）。本 skill 只管**视听情绪**，不管剧情。

## 工作流程

### 第 1 步：场景解构（七项，必须先做）

拿到场景图先用识图能力解出：① 空间结构（有无中轴／对称度）② 纵深通道（有无门中门／廊道／台阶）③ 光源方向与角度（必须物理明确：来自画左前上方的低角度等）④ 色调对比（暖冷如何对切）⑤ 材质与风格子类 ⑥ 前景遮挡物 ⑦ **人物可落位区（画面中央哪一块是空旷平坦的）**。

**铁律**：镜头设计必须从这些真实条件里长出来，不许架空发挥。

> 模型本身不支持读图时：先调度多模态子 Agent 取语义（画面类型／元素／空间结构／光线／材质），再用 `image-viewer` 的 PIL 脚本取像素结构（明暗占比／主色／边缘密度／分区色值），两者互补，不要只靠一种。

### 第 2 步：情绪语法方向二选一（先定这个，整组风格由此决定）

| | **A · 外扩型** | **B · 内塌型** |
|---|---|---|
| 适用情绪 | 震撼、敬畏、狂喜、压迫 | 伤痛、绝望、孤独、麻木 |
| 谁在动 | **镜头在动**（推轨、摇臂、环绕、俯拍），世界扑面而来 | **镜头不动**，全片唯一在动的是风、落叶、尘埃 |
| 主体位置 | 严格中轴正中，与建筑上下呼应 | **被挤到画面边角**，负空间占据主导 |
| 面部处理 | 明暗对半、瞳孔放大，看清一切 | 遮挡、剪影、虚焦，**什么都看不清** |
| 情绪落点 | 30 秒处**释放**、定格、庄严 | 30 秒处**不释放**，余痛挂在观众身上 |
| 光 | 暖光为主，光柱与浮尘，朝圣感 | 暖光成为**反讽**，大面积让位给冷影 |
| 声音 | 风声渐起、汇聚、收在一声檐铃 | 抽空、耳鸣、只剩心跳——**全片没有音乐** |

### 第 3 步：四拍情绪弧线

| 拍 | 占比 | A 外扩型 | B 内塌型 |
|---|---|---|---|
| ① 入景／立底 | 前 15% | 建立空间压迫，人物入画且身形极小 | 空镜立"世界照旧"的底，或人物只在边角 |
| ② 察觉／细节 | 中 30% | 从动作转为停顿（走→停→抬头） | 物件与身体局部（手、伤痕、碎物）替代语言 |
| ③ 峰值 | 约 25% | 感官过载，失控的身体细节 | 情绪外化顶点，但仍克制（跪伏、抵地、无声） |
| ④ 沉降／留白 | 后 30% | **释放**：静立、与环境对齐、定格 | **不释放**：人物离场、空镜、落叶覆盖痕迹 |

### 第 4 步：荷兰角逻辑二选一（本 skill 核心）

**开工前必须先定：这组的倾斜属于谁？** 两种逻辑互斥，选错整组就废。

**A · 内在曲线型（配外扩情绪）**
- 倾斜随人物内心升起，由他自己平复：`0° → 递增 → 峰值 → 平滑归零`。
- **归零即叙事**：倾斜消失＝他的世界观重新站稳。
- 参考梯度：0 / 3 / 6 / 8 / 12 / 15 / 22 / **25（峰值）** / 20 / 10 / 5 / 0 / 0

**B · 世界冷酷型（配内塌情绪）**
- **倾斜只属于他一个人**：他在画面里才倾斜（恒定小角度 3–10°，不追峰值），**他一不在画面（空镜）就立刻归零**。
- 题眼是那一记空镜：切到建筑或天空，画面完美水平 —— **世界从未为他斜过**。
- 参考梯度：0 / 0 / 3 / 5 / 6 / 7 / 8 / **0（空镜）** / 10 / 8 / 5 / 5→0（他离场，倾斜随之摆正）/ 0

共同禁忌：不许来回抖动式乱用；大角度／峰值优先给**大特写**（眼睛、手），不给全景——倾斜在特写上才最刺眼。小角度（3–5°）最容易被模型丢掉，必须用首帧预旋转兜底（见第 8 步）。

### 第 5 步：镜头语言配给

**不许全片同一套运镜。** 从池中分配，每镜只用一个主运镜：

对称中心构图｜极慢推轨 dolly in｜长焦压缩｜低角贴地跟拍｜过肩＋焦点转移 rack focus｜摇臂上升 crane up｜主观视角 POV｜手持呼吸晃动｜大特写 macro｜120fps 慢动作｜180° 环绕 orbit｜高角俯拍｜极慢后拉 dolly out｜**完全静止不动**（B 型情绪的主力运镜）｜硬切（**不用转场特效**）

**节奏**：时长 ÷ 镜数 ≈ 2–3 秒/镜（30 秒 ≈ 13 镜）。碎、快、不拖沓。

### 第 6 步：伤痛美学工具箱（B 型情绪专用，八手法）

内塌型情绪的关键不是"拍得惨"，而是**克制**。逐条对照落地：

| 手法 | 落地方式 | 为什么有效 |
|---|---|---|
| **克制** | 不嚎啕、不嘶吼、无眼泪（或仅一滴水痕） | 忍住的痛比爆发的痛高级，观众会自己往里补 |
| **让位** | 主体挤在画面边角，大片空景留给建筑 | 主体不居中 ＝ 不被世界善待 |
| **静止** | 镜头几乎不动，只有风和落叶在动 | 运镜一多，痛就被稀释 |
| **遮挡** | 柱、幡、门框吃掉半张脸 | 不给完整表情，逼观众共情 |
| **剪影** | 逆光成纯黑，欠曝 4 档 | 最痛的一刻最不需要看清脸 |
| **物件** | 半枚裂玉、断簪、烧剩的信、一只空袖 | 器物替代语言，痛被压缩进一个小东西里 |
| **光比** | 暖受光 vs 冷影在同一画面里对切 | 情绪分裂的物理显影 |
| **时间母题** | 落叶反复覆盖地面、掌心、他跪过的位置 | 时间抹平一切的视觉陈述 |

**空位叙事**：摇开镜头，落在一个"本该有人但空着"的位置（空石阶、空座位），风与落叶落上去。人不在画面，但画面处处是他。

### 第 7 步：分镜表字段（不得省略）

`镜号 | 时间码 | 时长 | 景别 | 运镜 | 构图/荷兰角 | 第一任务 | 光源`

- 每镜**只有一个第一任务**。
- 时间码必须首尾相接，**总时长精确等于目标时长**（交付前逐镜相加校验一次）。
- 光源列必须每镜写死方向，跨镜不得漂移。
- 首尾镜建议**同机位同光**形成闭环（B 型尤其必要：结尾空镜＝"世界照旧"的闭环）。

### 第 8 步：逐镜图生视频提示词

统一**前置**：「超写实…质感，16:9 横屏，8K 超精细，物理准确光照，参考图锁定场景：<场景要素清单>」
统一**后置**：「画面中不出现字幕｜禁止变脸换装、人数增减、站位反转、道具漂浮、自动转场特效｜光照方向全程保持<方向>不变」
- 每条都要**重复一次光照方向**，否则跨条生成时后几条会变顶光。
- 荷兰角写进提示词：「画面向右倾斜 22°（重度荷兰角）」。
- 素材要写明「哪张图锁什么」（场景图锁环境与光照／人物图锁面容服装／道具图锁道具）。
- **B 型情绪额外加**：禁止笑脸／大笑／嚎啕／张大嘴哭喊／夸张泪流满面／闪烁烛光／雨夜悲情套路；并把「画面中不出现任何人」（空镜镜号）写进**正面指令**，不能只写负面约束。
- **防"模型乱演"手段**：图生视频模型天生爱演——把低头理解成痛哭、跪伏理解成嘶喊。最有效的技术性解法是**不给脸**：遮挡、剪影、把脸埋进落叶。看不到脸，模型就没法演。

### 第 9 步：声音设计（容易被漏，但决定成败）

- A 型：风声渐起→汇聚→收在一声檐铃。
- B 型：**全片不上音乐**（一上弦乐，克制立刻崩塌）。底噪＝风、落叶摩擦、幡布拍打、远处檐铃偶尔一声；峰值段把环境音抽空，只留耳鸣与心跳；结尾收在一声悠长檐铃上，铃响完画面还静止半秒。

### 第 10 步：风险提示（必须给）

1. **模型会自动拉直地平线** → 提示词加英文强化 `Dutch angle, canted camera, tilted horizon, N degrees tilt`；3–10° 的小角度尤其容易丢，把参考图**先旋转同等角度**再作首帧喂入，效果最稳。
2. 高难度指令（瞳孔里映出建筑倒影、虹膜反光等）建议**单独生成多抽卡**或降级＋后期合成。
3. 环绕运镜易面容漂移 → 必须首帧锁身份 + 加「环绕过程中面部特征保持不变」。
4. 空镜镜号要防模型自行"补人"：写进正面指令。
5. 给一个**降级方案**（若平台限时更短，砍哪几镜仍保留四拍骨架）。
6. 若用户已有同场景的另一种情绪组，明确给出**语法反向对照表**（谁在动／主体位置／面部处理／落点），并说明两组可按硬切直接拼成上下篇。
