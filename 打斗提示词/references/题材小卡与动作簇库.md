> 题材小卡解决"词汇正确"，动作簇解决"节拍正确"。
> 生成【过程】前，必须先选 1 个题材小卡 + 1 个动作簇；再从该簇菜单中选 4-6 个节拍。
> 动作簇不是固定流程，是可选节拍菜单。不要每次机械套同一顺序。

#### T4 斗法连锁补充规则

当 T4 场景以雷法、阵法、结界、剑气对轰为主时，允许斗法大于近身连招，但法术节拍必须互相咬合，不要写成一关一关破解。

斗法连锁：

```
上一拍法术不得完全清零。
至少保留 1 个残余元素进入下一拍:
雷光残弧 / 阵纹余亮 / 云海压痕 / 剑气裂缝 / 护体光纹裂口 / 碎石悬浮轨迹。
下一拍必须利用、反转或放大这个残余元素, 形成连锁。
```

正确：

```
雷笼被女主斜挑切开一线, 但断开的雷弧没有消散,
反而沿青玉裂缝爬回她脚下, 修者只抬起两指,
残弧从女主脚下、身后云雾和剑锋侧面同时折返夹击。
```

错误：

```
修者打出掌心雷, 女主躲开。
修者又打出雷笼, 女主破开。
修者再打出巨雷, 女主劈开。
```

高位施法者压迫：

```
强者不靠频繁大动作制造威胁。
优先写: 指尖一点 / 袖袍一振 / 眼神下压 / 掌心翻转 / 双手合十。
法术从平台裂缝、身后云雾、脚下阵纹、剑锋侧面等多个空间位置合围。
表现"人不动, 空间在听他调度"。
```

## Part 4.5 · 题材动作簇库

> 每个动作簇按以下格式理解：

| 模块 | 作用 |
|---|---|
| 适用 | 什么时候选这个簇 |
| 结构适配 | 对应公式 A / B / C，避免把所有题材写成同一种打斗 |
| 开场锚点 | 这个簇怎样进入第一个画面，先建立什么空间/状态 |
| 中段任务 | 4-6 个节拍共同完成什么动作逻辑，不是随便堆招 |
| 结尾锚点 | 这个簇最后留下什么结果画面或物理证据 |
| 可选节拍菜单 | 从中选 4-6 个，不必全用 |
| 动作素材 | 当前簇可用动作/武术/能力词 |
| 环境反馈 | 当前簇应该触发的物理反馈 |
| 镜头素材 | 当前簇适合的镜头链 |
| 音效线索 | 当前簇应提取的声音 |
| 禁用 | 当前簇不该出现的东西 |
