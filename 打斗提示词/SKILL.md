# 打斗提示词（Seedance 2.5 专用）

## Overview

这是一个"给 AI 模型读的打斗视频 prompt 生成协议"，专门产出可直接喂给 **Seedance 2.5（SD2.5）/ 即梦 / Sora** 的打斗动作视频提示词。

核心定位（v5.1 剧情锁定版）：**保留原模板的动作密度、因果链、镜头贴附与生成强度，但取消会改写剧情的重编权限。** 本版适合承接上游已锁定的分镜 / 招式单元 / 关键动作链，把它们细化成稳定、可生成的视频 prompt。

- 默认生成一个 10-15 秒的完整动作单元
- 最终 prompt 目标字数 1200-1400 字，硬上限 1500 字
- 多场景、长剧情、跨时空内容必须拆成多个 prompt，不塞进同一段
- 输出时**不解释流程、不输出分析，只输出最终 prompt**

## 触发与输入

当用户出现以下任一意图时使用本 Skill：

- "给这段打斗写个 Seedance / 即梦 prompt""打斗提示词""战斗提示词"
- 提供剧本片段、已锁定分镜、招式单元、镜头表或明确动作链
- 要求"生成打斗/战斗/动作戏视频提示词"

**输入两种类型，处理方式完全不同：**

| 输入类型 | 处理方式 |
|---|---|
| 已锁定分镜 / 招式单元 / 镜头表 / 明确动作链 | 剧情结果、动作顺序、关键动作、视觉锚点、转场出口都是**硬约束**，模板只补动作衔接、物理反馈、镜头贴附、音效和生成友好表达 |
| 一句话粗略剧情 | 按原流程主动补动作细节，但不得改写用户明确指定的剧情结果、胜负关系、角色能力、武器法器和结尾去向 |

## 工作流程（严格按序执行）

执行时只做一件事，按以下流水线走：

```
读输入 -> 判断是否为锁定分镜 -> 锁定剧情结果/动作顺序/视觉锚点/出口
-> 判结构 -> 判题材 -> 选压力曲线 -> 选动作簇素材 -> 生成连招方向链
-> 逐拍绑定镜头贴附与物理化结果 -> 套字段
-> 按 1200-1400 字目标细化动作因果链 -> 自检 -> 输出 prompt
```

**规则优先级（冲突时按此裁决）：**

```
用户剧情与动作锁定 > 用户禁止改写项 > 固定输出格式 > 结构公式 > 当前题材小卡
> 动作连续性 > 动作簇素材 > 风格词 > 附录素材
```

### 第 1 步：剧情锁定层

先判断输入类型。

**若输入是已锁定分镜/招式单元/镜头表/明确动作链**：不得降维重编，必须先锁定动作顺序、关键结果、视觉锚点和本段出口，再进入题材、动作簇和镜头细化。内部先写一张"锁定动作卡"（不输出给用户），生成时严格遵守：

| 锁定字段 | 该写什么 | 禁止写什么 |
|---|---|---|
| 场景容器 | 地点、空间结构、主要材质、光源 | 改成另一个场景 |
| 角色与能力 | 角色、武器、法器、能力边界 | 换角色、换能力、换武器 |
| 单元入口 | 本段从哪个画面/动作进入 | 提前写上一单元完整过程 |
| 锁定动作节点 | 4-6 个必须保留的动作结果和顺序 | 打散顺序、替换关键动作 |
| 中段关键结果 | 本段最重要的局势变化 | 新增第二个同等级结果 |
| 单元出口 | 本段结束必须到达的位置、姿态或转场 | 改出口、提前进入下一单元高潮 |
| 必须保留视觉锚点 | 用户或上游指定的视觉锚点 | 删除、替换、挪到无关位置 |
| 禁止新增 | 不许出现的角色、能力、奇观、剧情结果 | 空着不写 |

锁定动作卡硬规则：

```
锁定动作节点必须按原顺序进入 prompt。
动作簇只能作为动作语言和微动作素材, 不能覆盖原动作链。
可以把一个锁定节点拆成 1-3 个微动作, 但微动作必须服务原节点结果。
可以补身位变化、攻防反应、环境反馈和镜头贴附。
不能新增胜负结果、转场结果、法器能力、角色登场或第二高潮。
```

**若输入只是一句话粗略剧情**，才使用剧情功能骨架：场景容器 / 主角状态 / 压力来源 / 冲突功能 / 中段功能结果 / 结尾功能结果。补全时仍不得改写用户明确指定的关键动作、视觉锚点和结尾结果。

**锁定节点抽取**：每个 10-15 秒单元保留上游锁定的 4-6 个动作节点，写成连续过程：

| 节点类型 | 从输入抽什么 | prompt 里怎么用 |
|---|---|---|
| 开场入口 | 当前场景 + 主角状态 + 主要威胁第一次显形 | 写进【起幅】/【起势】 |
| 动作节点 | 已锁定的动作顺序、结果、关键视觉锚点 | 按顺序写进【过程】，用动作簇增强力学和镜头贴附 |
| 中段关键结果 | 本单元最重要的局势变化 | 写成【过程】中最清楚的一次命中/锁定/失控/夺权 |
| 结尾出口 | 转场/胜负/坠落结果 + 终段空间位置 | 写进【结尾】，保持运动感 |

**锁定外新增控制**：锁定外内容不得作为新的剧情事件进入正文。只能被吸收为：微动作、压迫感、节奏感、环境余波、镜头遮挡、音效层。判断标准——若会改变锁定出口/动作顺序、新增第二个中段结果、需额外道具或镜头解释，一律禁止。

**剧本道具降权硬规则**：单段最多 1 个"过程主道具"，最多占用 2 个动作节拍；【起幅】允许 1 个一次性起手投掷物；道具完成格挡/破坏/封路后，节拍必须回到人物攻防。道具不是动作主体。

### 第 2 步：清理剧本输入

| 输入情况 | 处理方式 |
|---|---|
| 一句话剧本 | 主动补角色招式、场景物件、光源、物理后果、音效 |
| 含对白 | 去掉对白，转成表情、情绪、呼吸、嘶吼、动作节奏 |
| 含情绪 | 情绪转成运镜和节奏（如悲壮 → 慢推 + 低频环境音） |
| 含演员/IP | 不写真实演员或 IP 名，转成身形、服装、招式、气质 |
| 群战多人 | 合并群体，用代表性击倒 + 余波带倒 |
| 多场景跨切 | 拆成多个 10-15 秒单元，不塞进一个 prompt |
| 静态分镜 | 补成"画面里发生了什么 + 造成什么后果" |

### 第 3 步：判结构（先结构，后题材）

| 结构 | 适用 | 核心写法 |
|---|---|---|
| A 对打 | 两个或多个主体互相攻击 | 每个命中点写完整 6 变量因果链 |
| B 形态演化 | 变身/觉醒/异化/化神/单事件显化 | 起态 → 触发 → 分层覆盖 → 终态完成 |
| C 单人武学演绎 | 剑舞/拳路/无对手美学展示 | 起势 → 连续招式用"—"分隔 → 连续收势 |

混合剧本默认主走 A：变身后打斗 → 起幅用 B、过程和结尾用 A；打中觉醒 → 前半 A、结尾嵌入 B。

### 第 4 步：判题材（按顺序判断，命中更具体题材优先）

| 触发词 | 题材 |
|---|---|
| 恐怖/邪典/怨灵/无面人/鬼怪/Boss/反生理 | T6 邪典恐怖 |
| 机甲/装甲/赛博战士/变身/机械组装/粒子装甲 | T5 机甲变身 |
| 极速者/超音速/闪现位移/撞穿墙体/残影/音障 | T7 极速者 |
| 剑气/御空/法术/灵气/化神/神识/渡劫 | T4 玄幻仙侠 |
| 江湖/客栈/雨夜屋檐/刀剑/武林/侠客/古装真功夫 | T3 低魔武侠 |
| 写实科幻装备/赛博朋克/短促能量/仿生肢体/EMP/全息分身/局部装备强化 | T2 凡躯超英 |
| 拳脚/格斗/拳馆/街头/搏击/对打/雨巷/力量夸张但无装备能力 | T1 现代街战 |
| 无明确题材 | 默认 T1 现代街战 |

**T1/T2 边界硬规则**：只有"打穿单车、撞凹卷帘门、冲刺撞开障碍"等物理夸张，但没有装备/科技机制/能量释放/仿生肢体时，仍归 T1，写成"强化街战"。T2 必须有明确能力来源或科幻机制。

### 第 5 步：选动作压力曲线（同一段只选 1 条）

压力曲线不规定具体招式，只检查"每个节拍是否让局势变化"。

| 压力曲线 | 适用 | 局势变化 |
|---|---|---|
| 压迫递增型 | 强者逼弱者、窄巷、墙角 | 还能躲 → 勉强挡 → 被逼退 → 空间封死 → 终段命中 |
| 反制失败型 | 弱者有求生反击但力量差明显 | 被压制 → 短暂反击 → 对手硬吃 → 主动权被夺回 → 败退 |
| 诱敌反打型 | 主角冷静、技巧更高 | 退让 → 暴露破绽 → 借位闪开 → 反打关键点 → 收势 |
| 波峰波谷型 | 双方实力接近 | A 压制 → B 反压 → A 改招 → B 受挫 → 终段定局 |
| 蓄力爆点型 | 变身、机甲、仙侠大招 | 低压铺垫 → 层层蓄势 → 环境预兆 → 单次爆发 → 余波收束 |
| 群战扩散型 | 多敌围攻、怪物群 | 单点威胁 → 多方向包围 → 借力连带倒退 → 包围撕开 |
| 追逃逼近型 | 恐怖追杀、极速截击 | 远处显形 → 距离缩短 → 遮挡失效 → 近身擦过 → 尽头/截停 |
| 单人流转型 | 剑舞、拳路、无对手演绎 | 起势 → 连续变向 → 速度峰值 → 细节掠过 → 终段收在余波中 |

### 第 6 步：选动作簇 + 连招编排

从 `references/题材小卡与动作簇库.md` 的 **Part 4.5 动作簇库**中，根据锁定动作卡/功能骨架 + 题材 + 锁定节点 + 胜负关系，选 **1 个动作簇**，再从中选 4-6 个节拍。每个节拍必须调用该簇的动作素材 / 环境反馈 / 镜头素材，不得跨题材混用。

生成【过程】前，必须先在内部完成**连招编排四件套**（内部表不输出）：

1. **连招方向链**：先写 4-6 个方向/身位变化（如"左斜切入 → 右侧折返 → 正面压进 → 贴地横扫 → 垂直终击"），不先写华丽形容词。
2. **每拍动作因果**：方向/身位变化 → 招式/载体 → 命中或避开位置 → 接触点物理化 → 身体/环境后果 → 下一招衔接。
3. **镜头贴附动作路径**：镜头必须说明它贴着哪个动作、被什么遮挡、如何接到下一招，不得独立说"快速摇摄/切分/跟拍"。
4. **装饰词物理化**：抽象强度词（毁天灭地/震撼全场/极致爆发）不能直接进正文，必须转换成"当前题材载体 + 接触点物理现象 + 身体/环境后果 + 边界限制"，每拍最多 2 个物理化结果。

### 第 7 步：选镜头策略（每段 1 个）

| 镜头策略 | 适用 | 镜头立场 |
|---|---|---|
| 压迫贴身型 | 街战、追杀、弱者被压制 | 贴近被压迫者的呼吸和退路 |
| 兵刃核心型 | 武侠、仙侠近战、刀剑拆招 | 围绕兵刃轨迹和手腕变化 |
| 重量仰拍型 | 机甲、巨物、重击 | 从低位感受重量和压迫 |
| 高速追踪型 | 极速者、追逐、瞬移截击 | 追踪本体，残像只作辅证 |
| 恐怖遮挡型 | 怨灵、旧楼、反生理怪物 | 站在逃生者视角，信息故意不完整 |
| 大场面调度型 | 仙侠对轰、群战、云海、战场 | 先建立空间规模，再锁回主体 |
| 单人演绎流线型 | 剑舞、拳路、变身展示 | 沿身体和兵器运动线流动 |

镜头策略规则：镜头词可来自动作簇但必须被镜头策略统领；一段至少有 1 个重复视觉母题（水面/拳头前景/刀锋/门缝/残像路径）；结尾必须回收空间信息。

## 固定输出格式（字段名固定、顺序固定）

```
【整体风格】
整体风格: [风格组合 + 动作类型 + 画面质感],
[物理呈现方式 + 主体清晰要求 + 技术约束]

【角色卡】
- @图片1作为[主角/角色身份]: [外观锚点 + 武器/能力 + 动作倾向 + 本段攻守位置]
- @图片2作为[对手/角色身份]: [外观锚点 + 武器/能力 + 动作倾向 + 本段攻守位置]

【场景设定】
[地点 + 时间 + 光源 + 关键物件 + 可被破坏/响应的环境锚点]

【画面坐标】
[1-2 行: 只写开场空间定位。主体在画面左/右/中央/前景/深处 + 主要威胁从哪个方向进入]

【起幅】或【起势】
[对打/形态演化用【起幅】; 单人武学演绎用【起势】]

【过程】
[核心动作展开。战斗类 4-6 个连续攻防节点; 变身类 3-4 个阶段; 武学演绎 4-6 个连续招式]

【结尾】
[终段一击接结果爆发 / 转场坠入 / 压制完成, 镜头不断流]

【音效】
[逗号分隔, 只取本题材声音]

【禁止项】
文字/UI/水印/Logo/角标/可读文字/真实UI

【强制声明】
无背景音乐,仅保留环境音与人声;画面禁字幕/文字/水印/Logo;禁止可读文字;
```

### 格式硬规则

```
【整体风格】必须保留"整体风格:"开头。
【角色卡】必须使用"- @图片1作为..." "- @图片2作为..."格式。
不要把角色卡改写成"女主：""敌人：""主角："这种普通冒号格式。
即使用户没有上传图片, 也先按 @图片1/@图片2 作为占位写法输出。
【禁止项】【强制声明】必须原样输出, 不压缩改写。
```

### 可选字段（默认不输出）

- **【特效细节】**：适合 T4/T5/T6/T7 或公式 B，约束粒子、装甲、黑雾、光效边界。
- **【负面提示词】**：题材不稳定、用户要求、或主体易被特效吞没时使用。

可选字段必须放在【音效】之前。

### 字数与数量限制

- 目标 1200-1400 字，硬上限 1500 字；低于 1100 字通常视为信息不足。
- 字段预算：整体风格 100-140 / 角色卡 140-200 / 场景设定 130-190 / 画面坐标 50-80 / 起幅起势 150-220 / 过程 650-780 / 结尾 130-190 / 音效 80-130 / 固定末尾约 60。
- 战斗类【过程】必须写 4-6 个连续攻防节点，不得少于 4 个。每个节点至少含 1 攻防动作 + 1 位移/身位变化 + 1 命中或避开反馈 + 1 环境/镜头反馈。
- 音效 10-14 个，逗号分隔。
- 每个动作节拍必须至少调用：1 个动作/武术词 + 1 个环境反馈词 + 1 个镜头词。

### 【画面坐标】独立字段

只写一次，放在【场景设定】之后、【起幅】之前。只回答三件事：主体开场在画面哪里、威胁从哪个方向进入、空间纵深/退路在哪里。不要把坐标扩散到每个动作节拍。

### 动作连贯性默认规则

打斗类 prompt 默认追求连续性，不是 MV 式卡点展示。**默认禁止写**：0.5 秒定格、子弹时间、慢镜头编号、停顿半拍、命中停半拍、失焦回正、升格细节、时间恢复、画面冻结、悬停半拍。

除非用户明确要求慢动作/定格海报感/子弹时间，否则所有命中、破坏、转场都必须保持动作不断流。

## 三种结构的写法

### 结构 A：对打

每个核心命中点必须符合 6 变量公式：

```
[打击者] 用 [载体: 拳脚/兵器/特效/速度] 击中 [对手具体位置]
-> [受击反应] -> [环境响应] -> [镜头反馈]
```

示例：女主右脚蹬地转髋，中段侧踢踢中男主腹部 → 男主弯腰后退三步 → 后背撞上便利店玻璃门，玻璃震出蛛网纹 → 镜头轻震后立刻贴身跟上女主下一步追击。

### 结构 B：形态演化

公式：`[起态] -> [触发物/触发情绪] -> [分层覆盖] -> [终态完成, 镜头继续缓推]`

必须写清楚阶段：皮肤/衣物/装甲第一层变化 → 能量/粒子/黑雾第二层覆盖 → 头部/眼睛/武器/标志物最后完成 → 环境被触发（灰烬、雨滴、灯光、碎石、空气波纹）。不要直接跳终态。

### 结构 C：单人武学演绎

公式：`[起势] -> [连续招式, 用"—"分隔] -> [结尾: 终段一式 + 结果爆发 + 镜头不断流]`

注意：输出字段用【起势】替代【起幅】；不写对手、不写受击反应；重点写衣袂、兵器、脚步、风压、雨幕、落叶、地面介质；特效边界克制。此结构实测标杆不足，使用优先保守。

## 写作规则

1. **动作永远写成因果链**：不写"主角爆发出极致力量"，写"主角右拳击中对手胸口 → 护甲凹陷 → 倒飞撞进砖墙 → 墙面裂出蛛网纹 → 镜头一震后追上压迫"。
2. **特效是动作副产品**：顺序是 动作 → 命中 → 反应 → 环境 → 特效/镜头；错误顺序是"特效铺满屏幕 → 主体被吞没"。
3. **群战合并写**：不逐个写敌人，用"三人同时被刀风逼退""残余敌人退成半圈""一名代表性敌人被终段击倒"。
4. **角色卡要有功能**：写动作偏好（偏低扫、侧踢 vs 偏重拳、膝撞），不写外貌作文。弱势角色也必须有动作功能，至少 1 次有效主动动作（有效闪避/格挡/反制/换位），不等同于反杀。
5. **音效从画面里提取**：先写画面再"听"画面，只在对应题材使用特效音。
6. **道具退到人物之后**：道具只承担防守载体/命中载体/空间载体三种功能，完成后必须退场或变环境余波，不连续承担 3 个以上动作功能。

## 五个高危反例（必须避免）

1. **形容词堆叠**：✗"灼热雷霆撕裂虚空，能量震撼爆发" ✓"一拳击中怪物胸口 → 胸口内陷倒退两步 → 身后砖墙裂出蛛网纹 → 镜头一震后拉回稳定"。
2. **跨题材污染**：✗ 低魔武侠音效出现"机甲撞击、警笛" ✓ 只用"剑鸣、刀风啸声、兵刃碰撞、雨滴、衣料摩擦"。
3. **特效遮主体**：✗"漫天光效铺满屏幕，主角隐没在冲击波中" ✓ 主体轮廓始终清晰可读，特效是命中后的副产品。
4. **群战逐个流水账**：✗"第一个敌人挥刀，第二个敌人踢腿…" ✓ 合并群体，代表性击倒 + 余波带倒。
5. **镜头逻辑错误**：✗"一镜到底，切镜到反派" ✓"一镜到底，【镜内转向】到反派，【镜内推近】到拳头特写"；✗"全程剧烈晃动失焦" ✓"中段跟拍稳定，命中瞬间短促震动后继续追随"。
