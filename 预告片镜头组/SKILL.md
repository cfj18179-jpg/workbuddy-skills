# 预告片镜头组（30–50 秒预告片镜头设计）

## 与分集分镜的区别（先读这一条）

预告片**不是**分集分镜的缩写版。它是全新的叙事结构：

| 维度 | 分集分镜 | 预告片镜头组 |
|---|---|---|
| 叙事 | 顺叙，一集讲一集的事 | **非线性**：先给全剧最高点，再倒回最低点 |
| 时长/镜数 | 90s / 25–35 镜 | 30–50s / 13–25 镜（平均 1.8–2.3s/镜，更快更碎） |
| 台词 | 本集台词全出 | **只选金句**，一条一句，长句用"声音跨镜"承载 |
| 目的 | 讲清剧情 | 抓量：炸 → 惨 → 笑 → 压 → 爆 |

不要套用分集分镜技能里的三层工作流与场次衔接补全（预告片没有连续场次），只继承其中的**台词纪律**与**镜头级因果链补全**。

## 第 1 步：四道前置参数问询（问完再动手）

读完全剧后**不得立即输出**，先一次集中问清。缺哪问哪，已知的不问：

1. **画幅与平台**——竖屏 9:16（抖音/快手/红果）／横屏 16:9（B站/招商）／两版都要。竖屏决定大场面必须重构图。
2. **调性与剧透度**——①爽点前置·扮猪吃虎炸场（最抓量，会露身份）②悬念钩子·藏身份（只给异象与众生反应）③轻喜燃向·放大吐槽反差。
3. **交付层级**——①设计层+实操层（含 Seedance/即梦分条喂入）②仅设计层 ③只要镜头设计表。
4. **参考素材**——有无角色资产卡/剧照/服化方案文档。**有就必须先读**，造型描述与之逐字一致。

若用户已给项目资产文档，主动去项目目录找：`*_人物资产.txt`、`*_角色提示词.md`、`*_服化方案*.docx`、`*_场景资产.txt`、`*_道具资产.txt`。

## 第 2 步：六版块结构模板（爽点前置型）

| 版块 | 占比 | 功能 | 内容要点 |
|---|---|---|---|
| A 冷开场·高能前置 | **25–30%**（5–7 镜） | 把全剧最高点砸出来，并把"世界要亡"铺实 | 见下方「灾难七拍」 |
| B 起点·反差建立 | 16–18% | 5 镜，把主角踩到最低 | 日常挨打／被羞辱／脏活累活；**心声轨在此起**，跨镜贯穿 |
| C 金手指·机制 | 7–9% | 2 镜 | 系统面板／异象／众生反应，只给"面板＋蓝光打脸＋装死"，不解释 |
| D 连环爽点蒙太奇 | 18–22% | 4–6 镜 | 全剧名场面糖葫芦：一次装怂 → 一次秒破局，循环。**中间必须留 1 镜静场喜剧**（画面荒诞但不放台词） |
| E 真正的敌人 | 14–16% | 4 镜 | 巨手／魔镜定位／天轮抽灵／主角第一次"不装了"的瞳孔特写 |
| F 终局爆发 | 16–18% | 4 镜 | 反派跪地求饶 → 飞升渐变换装 → 招牌道具脱壳现真身 → 一剑 + 剧名叠出 |

### 冷开场「灾难七拍」（实测有效，勿压到 3 镜）

冷开场只给 3 镜（灾难→众生→招牌道具）会因**"绝望感不足"导致收尾金句炸不响**。铺到 5–7 镜：

1. **降**——大反派真身挤出云层／天幕裂开（先给"天压下来"的压迫感）
2. **毁**——一脚踏碎主峰／一掌拍平山门（给"权威被摧毁"的实感；补过程子镜：阴影先盖住匾额，再给崩塌）
3. **绝**——万人跪伏、断剑插地、弟子哭喊被尘土糊脸（给"人已经放弃"的群体反应）
4. **扛**——最后一个还在扛的人（宗主／长辈）撑剑站起、喷血在剑身、举剑嘶吼
5. **压**——反派巨掌覆盖全场，把刚燃起的希望再按死
6. **停**——**不给主角的脸**：一双沾泥的手按住招牌道具的木柄，指节一根根收紧（1.2s 慢镜，全片最强悬念点）
7. **翻**——招牌道具横扫遮满画面（遮挡切出）＋主角金句起于此镜

第 6 拍是整套结构的枢纽：观众先看到"那是一双干活的手"，再被道具填满画面，身份悬念才留得住。加长冷开场的时长缺口**从 D 段蒙太奇匀**，不要动 B（反差建立）和 F（终局爆发）。

**收尾金句**优先选"冷刀"式台词（反差越大越好），不要选燃句（燃句留给中段）。

## 第 3 步：时间码与语速配平

- 每镜 1.4–2.6s，全片平均 1.8–2.3s/镜；版块 A 与 F 的爆发镜可到 2.6s。
- 语速基准：高强度嘶吼 4.5–6 字/秒｜中速对白 3.2–4｜低语/心声 2.8–3.5。
- **长台词不占用单独镜**：用「声音轨」承载，标注起止时间码与承载镜号（如 `S4 起镜6 止镜10，跨5镜，42字/9.4s=4.5字/秒`）。
- 逐条做**语速校验列**，>6.5 字/秒的必须标 ⚠ 并给出解决方案（延长镜头／改画外气声／授权删改）。
- 全片总时长落在用户给的区间内（30–50s 取 47–50s 最划算）。

## 第 4 步：声画分离（硬要求）

任何一句台词，画面只在说话人开口的 0.5 秒内给他本人，其余时长一律切走——切听话者反应、切相关道具特写、切环境空镜、切其他在场人物动作。**每句台词都要在设计表里落定具体切法**，不能只写"台词：XXX"。

## 第 5 步：台词逐字纪律（不可妥协）

- 引用剧本台词**必须完整、逐字**，禁用省略号缩写、漏写、擅自删改。
- 用不了的长句就**不用**，绝不用"半句"。若确需缩短，必须交付两版（严格原文版 + 优化版）并标注差异，让用户选。

## 第 6 步：镜头级因果链补全（预告片同样要做）

对每一对相邻镜头问一句："这个变化，观众能看到它一步步发生吗？"缺了就补 1–3 秒过程子镜，标注「**本版补全·过程镜头**」。四类：

1. **能量传导**——法术/光/电/毒：源头亮起 → 沿路径蔓延 → 末端响应（例：金光先自胸口亮起 → 沿双唇蔓延 → 对方体表浮现金纹）。
2. **动作轨迹**——起手 → 轨迹 → 落点（例：鞭身弧线 → 倒刺勾住衣料 → 衣料撕开 → 血珠溅地）。
3. **状态渐变**——半程渐变，不能换装式硬跳（例：灰布衣自下而上崩解成飞灰 → 光点汇聚 → 织成新袍裹身）。
4. **空间位移**——跨位置必须给"移动中"。

过程镜头控制在 1–3 秒，是"交代"不是"展开"。

## 第 7 步：视觉节拍器

选定**一件贯穿全片的道具**（通常就是主角的招牌道具，如扫帚/铲子/算盘），在片中重复出现 5–8 次，首尾各用一次"填满画面"的切出（首镜遮挡切出／末镜光爆切出）构成闭环。它同时解决：镜头连续性差、转场生硬、观众记不住主角三个问题。

## 第 8 步：交付格式（镜头设计表）

```
一、导演基调卡（类型/一句话卖点/核心反差/情绪曲线/节奏原则/剪辑铁律/视觉锚点/结构逻辑）
二、正片镜头表 —— 按版块分组，列：镜号｜时间码｜时长｜景别·运镜｜画面内容（标注竖屏构图）｜声音
三、台词/声音轨 —— 列：序｜台词原文（逐字）｜出处集数｜承载镜号｜时间码｜语速校验
四、片尾彩蛋（独立于正片时长）
五、镜头级因果链补全清单（本版补全·过程镜头）
六、30 秒精简版删减建议（给出保留镜号清单）
七、资产/造型对应表（角色｜造型版本｜出现镜号｜造型要点）
八、风险提示（资产缺口/竖屏重构/台词纪律声明/语速告警/道具穿帮）
```

新增内容一律用「**本版补全**」标记，方便用户回退。

## 禁止事项

- 禁止未确认画幅/调性就动笔（竖屏与横屏的构图逻辑完全不同）。
- 禁止把预告片当成"分集的浓缩"，禁止顺叙铺陈。
- 禁止截断剧本台词、禁止擅自改词。
- 禁止只给抽象描述，画面内容必须是可拍摄/可生成的具体指令。
- 禁止镜头间"因→果"直接跳切而缺过程镜头。
- 禁止全片静帧接静帧；每镜必须带运动。
- 禁止只用燃句收尾（燃句给中段，收尾要冷刀）。

## 附：读本地 docx 剧本的技术路径（实测）

1. 走 `tencent-local-office-edit` 技能：`python edsdk.py call open_file --json '{"file_path":"<绝对路径>","file_type":"doc"}'` → 返回的 `file_id` 通常就是路径本身。
2. `doc_resolve_document_structure` 参数：`{"file_id":"<路径>","mode":"compact","limit":0,"text_preview_length":200}`（limit=0 不分页，可拿全文）。
3. **输出必须落盘再加工**：60 集剧本约 3186 节点、7 万字符，接口返回 JSON 约 600KB，不可直接读入上下文。落盘后用脚本抽 `nodes[].text_preview`（含 children 递归）拼成纯文本，约 200KB，再分段 Read。
4. 短剧剧本常常**没有 Heading 样式**（`doc_get_outline` 返回空数组），只能靠 `第N集` / `N-N：` 文本行正则切分。
5. Windows 下 Bash 的 PATH 常被 shim 破坏，需先 `export PATH="/c/Users/.../PortableGit/versions/x/usr/bin:/c/Windows/System32:/c/Windows:$PATH"`；PowerShell 工具在部分机器上**不回显 stdout**，取输出一律走 Bash + python 绝对路径。
