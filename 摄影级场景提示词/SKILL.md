# 摄影级场景提示词（建筑 / 环境 / 大场景写实）

## 适用场景

用户要写「极致写实的建筑摄影」「真实感大场景」「城堡/城市/废墟/山川空镜」类生图提示词，或要求
「学习/模仿某段写实场景提示词的写法」。也适用于短剧项目的**场景资产卡空镜**。

不适用：角色三视图资产卡（走 `全资产大师`）、打斗动作（走 `打斗提示词`）。

## 核心原则

1. **摄影先行，不要绘画先行。** 第一句就要把画面定义成「一张被拍下来的照片」，而不是「一幅画」。
   开了这个头，AI 会自动调用摄影的物理规律（透视、动态范围、景深）。
2. **能写数字就不写形容词。** 「超广角」不如「24mm 全画幅」；「俯视角」不如「60° 下倾」。
   数字是 AI 最不容易误读的语义。
3. **每个正向要求必配一条负向排除。** 这是本文档最重要的一条。AI 默认倾向是"用力过猛"，
   「要什么」只能给出方向，「不要什么」才能压住过冲。
4. **量词克制三件套**：`少量` / `轻微` / `低强度`。凡涉及特效、光效、机械点缀，一律加量词上限。
5. **长度分档交付。** 用户的生图工具（如 Neo-G 3.8 Flash）有硬长度限制，会报「提示词过长」。
   只交付一个长版本是错的，必须同时给精简版。
6. **用户指定色调时，走下面的「色彩分级模块」，不要只加一个形容词。** 说「青蓝色调」「电影感」
   要落成可执行参数：色相／暗部色相／高光去饱和／饱和度压幅／明暗曲线／胶片锚／镜头语言，
   并必配对应负向排除。两条铁律不可破：**肤色保留极弱暖调**（否则僵尸绿）、**全片只留一个高饱和暖色锚点**（否则调色崩塌）。
7. **交付多版本时把种子写清楚。** 同种子可锁机位做调色 A/B 对比；整批换色调重出时给新种子区间（如原种子 +5000），避免与旧版结果混淆。

## 十二层写作骨架

顺序是「由宏观到微观、由物理到美学」，不要打乱。

| 层 | 模块 | 写法要点 |
|----|------|----------|
| 01 | 媒介与风格锚定 | 「极致写实的建筑摄影 / 电影级实景摄影」。先定媒介，不定风格词 |
| 02 | 主体＋形容词三连 | 2–3 个气质形容词 + 材质/题材/类型名词（宏伟·神圣·繁荣 + 白色蒸汽幻想帝国城堡）|
| 03 | 环境·季节·时令 | 「真实自然的 + 季节 + 时间 + 天色」。**必须有「真实自然的」来对抗幻想感** |
| 04 | 机位与镜头（核心）| 高度 / 景别 / 镜头焦段 / 倾斜角 / 相对主体的高度关系。**中英术语对照**写一次关键术语 |
| 05 | 构图显式定义 | 逐项说明「什么占据画面大部分面积」「地平线在哪或不可见」＋ 布局要素枚举 |
| 06 | 真实性约束 | 准确透视 · 合理比例 · 结构严谨 · 可信的可建造感（反幻觉条款）|
| 07 | 材质统一体系 | 「统一的 X 材质体系」＋「X 占绝对视觉主体」＋ 风格融合 ＋ 真实材料细节（接缝/纹理）|
| 08 | 光照与曝光 | 光源 + 色温方向 + 边缘光 + **曝光控制（暗部留细节，不是漆黑剪影）** + 空气透视/薄雾 |
| 09 | 点缀＋克制条款 | 装饰元素的**数量上限**＋**不覆盖主体的声明**＋ 配套负向排除 |
| 10 | 画质技术参数 | HDR · 全局光照 · 真实反射 · 真实阴影 · 精确材质 · 8K |
| 11 | 情绪落点 | 4–8 个双字情绪词（庄严 宁静 神圣 洁净 完整 宏伟）。放中后段，不放开头 |
| 12 | 胶片色彩锚定 | 具名胶片（Fuji 400H / Kodak Portra）+ 颗粒 + 「无明显数码锐化」。**与 01 首尾呼应** |

## 五个可迁移技巧

### 1. 正反双写（核心）

| 正向锁定 | 负向排除 |
|----------|----------|
| 暗部保留丰富细节，主体曝光清晰 | 不是漆黑剪影 |
| 黄铜仅作克制的金色点缀 | 不覆盖白色建筑主体 |
| 少量蒸汽，符合真实流体效果 | 没有夸张霓虹光和魔法能量 |
| 细腻胶片颗粒，轻微光晕 | 无明显数码锐化 |

**句式**：`A，是/有 X` → `不是/没有 Y`。成对出现，不要只写一半。

### 2. 量词克制

`少量` / `轻微` / `低强度` / `仅作为` / `恰如其分地`。任何特效、光源、装饰物前面都挂一个。

### 3. 数值化参数

24mm 全画幅 · 60° 下倾 · 高出尖塔数百米 · 满月 · HDR · 8K · Fuji 400H。
代替「超广角 / 大俯角 / 很高 / 很亮」这类模糊词。

### 4. 机位显式定义

一段里要同时给出五件事：**高度**（相对主体的绝对关系）、**景别**、**焦段**、**倾斜角**、**术语名**。
关键术语给中英双写（`high-angle oblique aerial view`），锁死语义。

### 5. 首尾呼应锚定

开头定媒介（01），结尾再重复一次核心锚点（12）。
写实类提示词的收尾必须复述「真实摄影质感 / 物理正确光照 / 超精细细节」。

## 三档长度（按生图工具限制选）

| 档位 | 字数 | 用途 |
|------|------|------|
| 全量版 | 800–1200 字 | 首轮出图、需要最高可控性时 |
| 精简版 | 中文 ~260 字 / 英文 ~95 词 | **默认档**，适配 Neo-G 3.8 Flash 等有长度限制的工具 |
| 极简版 | 英文 ~45 词 | 被报「提示词过长」时的兜底 |

**精简版删减顺序**（从后往前砍，不要砍机位与光照）：
① 画质技术词表只留 HDR / 8K / 胶片 → ② 情绪词只留 3 个 → ③ 材质特征枚举减半 →
④ 构图分项枚举合并 → ⑤ 「可信的可建造感」等约束句合并成一句。
**绝不删**：机位与焦段、曝光的负向排除、量词上限。

## 色彩分级模块（指定色调时追加）

用户说「青蓝色调」「电影感」「冷调」「青橙」时，不要只在提示词里加一个形容词，要按下面这套**可执行参数**写进第 08/09/11/12 层。

### 青蓝电影感（teal-cyan，工业／悬念／病态题材首选）

| 项 | 参数 |
|---|---|
| 主色相 | **200–210°（青蓝）**，占画面 70% 以上 |
| 暗部 | **185–195°（青绿 teal）**，暗部推入青绿，不是黑也不是蓝 |
| 高光 | 208–215°，**去饱和至 8–15%**，呈"冷银白"，绝不发黄 |
| 中间调 | 偏青，**饱和度压低 20–30%** |
| 明暗 | **抬黑（lifted blacks）8–12 IRE** + 低对比 log 感 + 高光柔和滚降 |
| 主光 | 5600–6500K 冷青 + **青绿环境反射补光**（暗部靠反射光填青，不靠加亮） |
| 材质 | 金属／水泥／纸箱一律**降到近乎消色**，色彩全部由光染色 |
| 胶片 | **Fujifilm Eterna 500T（夜）/ Eterna 250D（日）**——Eterna 的青绿暗部是青蓝调的经典来源 |
| 镜头 | 变形宽银幕感：横向细长蓝色眩光 ≤1 道、椭圆焦外（oval bokeh）、Black Pro-Mist 1/8 高光柔化、高光边缘**极轻微红色 halation** |
| 负向 | 暖黄日光感、橙色主导、高饱和彩色、正午硬光、死黑暗部、数码锐化 |

**⚠️ 两条必守铁律：**

1. **肤色必须保留 5–10% 极弱暖调（25–35° 色相）**。纯冷青会把人物调成"僵尸绿／尸体青"，这是青蓝调最常见的翻车点。人物靠**明度比环境高 1–1.5 档**分离，而不是靠色相分离。色重、纹理深的中老年角色（皱纹多、肤色深）尤其容易翻车，需单独强化暖调保留。
2. **保留唯一强色锚点**。青蓝单色世界里，要指定**一处**高饱和暖色作为视觉爆点（如红色急停钮、红色尾灯），其余暖色全部压掉、连路灯也要从橙黄改为冷白偏青。没有锚点的纯青蓝画面会"平"；锚点太多则调色崩塌。

### 青橙（teal & orange，商业／人物题材）

与青蓝相反：**暗部与背景走青绿，肤色与暖光源走橙**，形成色相分离。参数：暗部 190°、肤色推向 30–40° 并提亮 1 档、高光保留暖调；负向改为"肤色偏青、背景偏暖"。

### 其他常用锚定速查

| 色调 | 胶片锚 | 关键参数 |
|---|---|---|
| 冷白工业（中性写实） | Kodak Vision3 500T | 4000–5000K，自然色彩分级，无强色调偏移 |
| 病态绿（惊悚） | Fuji Eterna 500T 再压 | 主色相 120–150°，皮肤去暖但留黄 |
| 暖复古（年代） | Kodak Portra 400 | 高光暖黄、暗部棕、低对比 |
| 银白冷（科幻） | Kodak Vision3 250D + 银盐 | 高光冷银白、暗部中性蓝灰、饱和度压至 60% |

## 常见坑

- **只写正向不写负向** → 画面必然过曝、过饱和、特效堆砌。这是最大的失败原因。
- **情绪词放开头** → AI 会把「神圣」渲染成宗教光效、「繁荣」渲染成密密麻麻的楼，喧宾夺主。
- **机位写得模糊**（「俯视角度」）→ AI 默认给 30–45°，出不来真正的高空鸟瞰。必须给角度 + 高度关系。
- **材质没声明占比**（「白色大理石建筑」）→ AI 会让黄铜/深色元素吃掉一半画面。必须写「占据绝对视觉主体」。
- **忘了空气透视** → 远景糊成一团，失去尺度感与纵深。
- **合金/奇幻元素不加量词** → 生成「魔法能量」「霓虹光」。必须补「没有夸张霓虹光和魔法能量」。
