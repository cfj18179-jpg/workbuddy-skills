# 分镜提案（五方案比稿 · Storyboard Pitch）

## Overview

把「分镜设计」从一次性产出改成**两阶段比稿**：

1. **提案阶段（必做，不得跳过）** —— 读完剧本后先给出 **5 个导演方向截然不同**的分镜方案，每案用「一句话导演概念 + 开场三镜样例」让人一眼看出差别。
2. **展开阶段（必须等用户选）** —— 用户选定某一案（或指明跨案组合）后，才产出完整分镜表与可直接粘贴的视频提示词。

核心价值：**不替用户做审美决定**。直接给一版分镜，用户只能说「不是我想要的」；给五版方向不同的方案，用户能明确指出「要 B 案的节奏 + D 案的距离」。

---

## 何时用 / 何时不用

**用**：用户给剧本、大纲、故事梗概或单场片段，要「分镜 / 镜头设计 / 视频提示词」，且没有明确要求某个既定套路。题材不限。

**转交**（用户显式点名本技能时一律不转交）：
- 用户要做的是**短剧**（竖屏爽文、单集 90 秒左右、强钩子链），且没提「给几个方案选」→ 建议改用 `knee-li-one` 或 `短剧视频生成提示词`，那两个对短剧的钩子密度、台词一字不差、单条切条有更严的约束。
- 用户要的是无剧本**单场景情绪镜头组** → `美学镜头组`。
- 用户要的是 **30–50 秒预告片** → `预告片镜头组`。
- 用户要的是**打斗 / 动作 video prompt** → `打斗提示词`。
- 用户明确说「分镜提案」「五案比稿」「给我几个方案挑」→ 一律用本技能，即使题材是短剧。

判断不了就问，不要猜。

## 关卡 0：前置参数问询（强制）

拿到剧本后**先问再做**，用一次提问把下列参数问清（不要分多轮挤牙膏）：

| 参数 | 说明 | 缺省值（用户不答时用） |
|---|---|---|
| 目标成片时长 | 单集成片 / 整片时长 | 按剧本声明；无声明则按场景数估算后报给用户确认 |
| 画幅比例 | 16:9 / 9:16 / 2.39:1 / 1:1 | 16:9 |
| 目标生成模型 | Seedance 2.5 / Wan 万相 / MiniMax 海螺 / Sora / Veo / 可灵 | Seedance 2.5 |
| 剧本完整度 | 完整剧本 / 只有大纲 / 单场片段 | 据实判定；只有大纲时先走 `references/01` 的大纲补全路径 |
| 是否有角色 / 场景资产图 | 有则提示词用素材引用锁身份 | 无（纯文生视频） |
| 是否已有偏好方向 | 用户心里有数的话直接说 | 无 → 进入五案比稿 |

若用户已明确给出全部参数，跳过问询直接进关卡 1，不要在回复里复述一遍再问。

---

## 关卡 1：总导演 · 剧本剖析

通读剧本，输出 **五维剖析** 作为五案提案的共同地基（详细方法见 `references/02`）：

1. **类型与受众** —— 决定镜头语汇边界（广告可以形式化，纪实不能）。
2. **核心冲突** —— 全片最不能含糊的那一场，五案都必须保证它成立。
3. **人物弧线** —— 主角在这一段里的状态位移，决定该给近景还是远景。
4. **爽点 / 钩子链** —— 情绪高点的时间位置，决定节奏曲线怎么铺。
5. **时空结构** —— 场景数量、跳跃程度，决定是否需要补桥接镜头。

剖析结果**摘要给用户看**（半屏以内），不要长篇复述剧情。

---

## 关卡 2：五案提案（核心）

详细方法、方向原型库、提案卡模板见 **`references/03`**。此处只列硬约束：

- **必须恰好 5 案**（用户另有要求除外）。每案必须有**画面感的名字**，禁止「方案一 / 方案二」。
- **五案必须互斥**：五案要在下面五条轴上分别主导不同维度，做到「换任何一版，拍出来是另一部片」：
  - 节奏轴：长镜滞缓 ↔ 碎切冲刺
  - 距离轴：远景环境 ↔ 近景微相
  - 运动轴：固定机位 ↔ 手持 / 跟拍
  - 视角轴：客观旁观 ↔ 主观 POV
  - 形式轴：自然写实 ↔ 强形式感
- **每案必须写「开场三镜样例」** —— 用真实镜头语言写出前 3 个镜（景别 + 画面 + 秒数），这是用户判断差异的关键依据，禁止写成抽象形容词。
- **每案必须写「不选它的理由」** —— 诚实标注代价（成本、对模型能力的要求、容易拍砸的地方）。
- 写完后跑 `scripts/pitch_check.py` 做互斥性校验，**有雷同案必须重做**，不能带着告警往下走。

提案卡模板（五案各自一份）：

```
===== 提案卡 [A] 《代号名》 =====
一句话导演概念：≤30 字，说清这一版「怎么拍」
镜头语法取向：主导景别 / 主导运镜 / 切换节奏 / 平均镜头时长
节奏曲线：[0-15s 铺垫 → 15-40s 加压 → 40-60s 爆发 → 60-70s 余味]
开场三镜样例：
  镜1（Xs）……
  镜2（Xs）……
  镜3（Xs）……
对本片的优势：……
代价与风险：……
预估成本：约 N 个镜头 / N 条生成
选它的理由：……
不选它的理由：……
```

## 关卡 3：用户选定（强制停止点）

提案卡输出后**必须停下来等待选择**，用提问工具或直接提问均可。可接受三种回应：

1. **选其一** —— 代号 A/B/C/D/E。
2. **跨案组合** —— 用户指明「主案 + 借用的元素」（如「C 案的距离 + B 案的节奏」）。以主案的镜头语法为骨架，把借用元素显式写进后续分镜表的「方案依据」行，并复述一遍组合规则让用户确认。
3. **全部推翻** —— 问清「哪个方向都不对在哪」，回到关卡 1 重做，**至少再出一轮五案**，不要退化成单案直给。

**禁止**：自行替用户选定、默认选第一案、或一边假装在问一边已经把完整版写完。

---

## 关卡 4：分镜导演 · 展开完整分镜表

按选定方案展开。字段模板与填写规范见 `references/06`。表格形式：

| 镜号 | 时间码 | 时长 | 景别 | 运镜 | 画面内容 | 台词 | 声音 | 备注 |
|---|---|---|---|---|---|---|---|---|

硬性规则：

- **镜数 = 时长 ÷ 3~4 秒**（抒情基调靠近 4 秒，冲击基调靠近 3 秒）；某一案若定义为「长镜流」，平均镜头时长可放宽到 6–10 秒并在备注写明依据。
- **声画分离**：人物说话时画面不全程给说话本人，切听话者反应 / 环境空镜 / 道具特写 / 其他在场人物。只有开口瞬间给说话者，随后切走。
- **台词必须一字不差**，且**写在真正会被粘贴给模型的可执行代码块正文里**（格式：`※台词：角色（口型/画外/群杂，时长）："原文"`）。只写在文末核对表 = 台词全丢，属违约。
- 需要省略或修改台词时，**必须交付两版**：严格按剧本的原版 + 优化版，明确标注差异让用户选。禁止单方面删改。
- 剧本中的画面内文字 / 字幕、▲动作行、转场标记同样不得丢。剧本文字有误（重复行、错字）按原意处理并**在产出中标注**，不静默修正。
- 剧本跳跃处补桥接镜头（集首衔接、场景跳跃、台词拆段、未出场人物去向、情绪外化动作）。
- 涉及能量传递 / 动作结果 / 状态变化的镜头，补齐「因→过程→果」三段，**禁止瞬移**。

## 关卡 5：提示词设计师 · 核心层 + 适配壳

采用**核心层 + 适配壳**结构（详见 `references/05`）：

- **核心层（模型无关）**：`主体 + 动作 + 环境 + 光线 + 构图 + 机位运动 + 时长`，用电影语言写成一段自然语言，不出现任何厂商私有语法。
- **适配壳（按目标模型追加）**：把核心层包装成该模型能稳定执行的格式——素材引用方式、时长 / 画幅参数、负面约束清单、镜头运动指令写法、原生音频选项等。

写作铁律：

- 光线必须有**物理来源**（窗光 / 台灯 / 霓虹 / 篝火），禁止无来源的「氛围光」式堆词。
- 禁止空词（唯美、史诗感、高级感、有质感、电影感）——换成可拍摄的具体描述。
- 默认**硬切**，不写溶解 / 叠化，除非用户要求。
- 口型镜头（需要明确对白的近景）单条 ≤4 秒。
- 负面约束按模型能力给，不要写出模型不支持的反义结构。

模型参数（时长上限、分辨率、私有语法）更新频繁，**不确定时查官方文档或问用户，不要凭记忆硬写**。

## 关卡 6：交付前审查（不过不许交付）

```bash
# 提案阶段
python scripts/pitch_check.py <提案文件路径>

# 展开阶段
python scripts/storyboard_check.py <分镜表文件> --duration <目标秒数> [--script <剧本文件>]
```

两项都必须通过（退出码 0）。失败则回改后重跑，**禁止带着未通过项声称已交付**。

`storyboard_check.py` 检查：时长合计与目标时长的偏差、镜数是否落在时长÷3~4 秒区间、单镜时长是否超界限、提示词条数与镜数是否匹配、剧本台词是否落到可执行代码块正文（双指标）、禁空词扫描。

台词需要更高强度审查时，可加跑 `~/.workbuddy/skills/短剧视频生成提示词/scripts/script_audit.py`（跨技能引用，缺失时跳过即可）。

---

## 铁律清单（每次都要满足）

1. 五案提案**不可跳过**，且必须互斥、有画面感的名字、有开场三镜样例。
2. **必须等用户选**，禁止代选、禁止默认第一案。
3. 台词**一字不差 + 落在可执行代码块正文内**。
4. 要删改台词 → **原版 + 优化版两版交付**。
5. 光线有物理来源、禁空词、默认硬切、口型镜 ≤4 秒。
6. 交付前脚本必过，不通过不交付。
7. 剧本笔误按原意处理并标注，不静默修正；**新增台词禁止**。
