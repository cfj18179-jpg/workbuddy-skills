# 多模型适配壳

## 一、核心层：七要素自然语言（模型无关）

先把每一镜写成一段**不给任何模型也能看懂**的电影语言，再套壳。七要素顺序固定：

```
[主体] + [动作/状态] + [环境] + [光线（含来源）] + [构图/角度] + [机位运动] + [时长]
```

示例（核心层）：

> 三十来岁的男人穿着洗旧的蓝色工装外套，背对镜头坐在窗前的小木凳上，右手缓慢拉开抽屉取出一只旧怀表，拇指在表盖上蹭了两下。身后是昏暗的木墙与半掩的布帘。清晨低角度的日光从右侧木格窗斜射进来，在他侧脸和手背投出细长栅格阴影，其余部分沉在暗部。中近景，机位略低于视线，固定不动，构图偏右留出左侧负空间。约 4 秒。

**核心层纪律**：
- 不出现任何厂商私有语法（@引用、专属参数名、中括号标签）。
- 一镜一个核心层，不同镜之间不互相引用（「同上」「接上镜」不允许）。
- 时间、数量、方位用具体值（「约 4 秒」「画面右侧 1/3」），不用模糊词。
- 禁止空词：唯美、史诗感、高级感、有质感、电影感、氛围感、震撼、视觉冲击力 —— 一律替换成可拍摄的具体内容。

## 二、适配壳

> ⚠️ 生成模型的时长上限、分辨率档位、私有语法更新非常快。**使用前核对官方文档或问用户**；若不确定，就在产出里标注「以下参数请以当前官方为准」，不要硬写过时数字。

### Seedance 2.5（即梦 / 豆包系）
- 采用**图生视频优先**：有角色资产图时用素材引用锁身份，一致性远高于纯文生。
- 支持素材引用（@角色名 / @场景名）与参考音频锁声线。
- 支持多比例画幅（16:9 / 9:16 等）与多档时长。
- 负面约束：用「不要出现：变形的手指、多余肢体、字幕、水印、忽明忽暗」这类**列举式**，不用长句描述。
- 拆分：超过单条上限的镜，按「动作一口气」为界拆，不要任意等分。

### Wan 万相（阿里）
- 中文语义理解好，长句中文描述稳定。
- 支持首尾帧控制，起止画面明确的镜头用它更稳。
- 运动幅度偏保守，激进的运动口令要拆成多段。

### MiniMax 海螺 H3
- 物理运动与人物表演自然度高，动作戏优先。
- 支持镜头运动指令，可直接写「推近 / 左摇 / 跟随」类口令。
- 不适合超高对比的画面，高光容易溢出、暗部易糊。

### Sora
- 对长句语义的理解力强，可以承载复杂场景描述。
- 世界一致性较好，适合多元素同框。
- 对「精确到秒」的执行不稳，时长靠后期裁切。

### Veo（Google）
- 原生音频能力强，可在提示词里描述环境音与配乐方向。
- 写画面时把「可听见 XXX」一起写上，一致性更好。
- 对产品 / 材质细节表现稳。

### 可灵 Kling
- 支持首尾帧、较长的单条时长、运动笔刷类控制。
- 适合需要明确起止画面的转场镜。
- 运动强度可调，动势大的段落要把强度写清楚。

## 三、通用负面约束清单（按需要裁剪）

```
不要出现：多余的手指或肢体、手指粘连变形、面部崩坏、五官漂移、
服装突然改变、角色身份突变、画面忽明忽暗、闪烁、卡顿、
字幕、水印、logo、过曝死白、暗部死黑、涂抹感、油画滤镜
```

**写法纪律**：负面项用**名词列举**，不用否定描述（「不要让画面不稳定」无效，「闪烁、抖动」有效）。项数控制在 10 条以内，过多会压制正常生成。

## 四、核心层 → 适配壳的转换示例（Seedance 2.5）

```
【核心层】同上示例

【适配壳 · Seedance 2.5】
@男人_工装版 坐在窗前木凳上，背对镜头，右手拉开抽屉取出旧怀表，
拇指摩挲表盖，动作缓慢连贯；
@昏暗木屋_清晨。清晨低角度日光自右侧木格窗斜射，在侧脸与手背投出栅格阴影，
其余沉暗；中近景，略低于视线，固定机位，构图偏右留左侧负空间。
16:9，约 4 秒。
不要出现：变形的手指、多余肢体、字幕、水印、忽明忽暗、服装突变。
```

## 五、切条与合并规则

- 单条上限是**上限不是目标段长** —— 不要因为上限是 10 秒就把每镜都写成 10 秒。
- 相邻同场次且合计不超过上限的条**必须合并**，否则会因为重复起手导致风格不一致。
- 条数下限 = ⌈总时长 ÷ 单条上限⌉，交付前用 `storyboard_check.py` 校验。
- 每条生成完后要人工接管：检查动作是否完整、有无崩坏帧或多余帧，不合格重抽而不是硬裁。
