# 五案提案生成法（本技能核心）

## 一、为什么必须五案，为什么必须互斥

用户说不清自己想要什么，但能很快说出「这几个都不对」。所以提案的价值不在数量，在**覆盖面**：

- 五案雷同（都是同一种调性换个词）= 白做，等于把选择题变成了判断题。
- 五案互斥 = 用户被迫表态「我要哪种」，选择本身就帮他把审美偏好说清楚了。

判定互斥的唯一标准：**换任何一版，拍出来应当是另一部片**。如果用户看完五案说「差不多」，就是失败，必须重做。

---

## 二、互斥五轴

提案时按下表逐轴取值，**五案必须在至少三条轴上落在不同端点**。

| 轴 | 端点 A | 中间 | 端点 B |
|---|---|---|---|
| 节奏轴 | 长镜滞缓（平均 6–10s，少切） | 常规叙事（3–4s） | 碎切冲刺（1.5–2.5s，硬切密集） |
| 距离轴 | 远景环境（人物渺小、多空镜） | 中景为主 | 近景微相（特写轰炸、微表情） |
| 运动轴 | 固定机位（画内调度） | 轻微推移 | 手持 / 跟拍（呼吸感、晃动） |
| 视角轴 | 客观旁观（第四面墙） | 过肩正反打 | 主观 POV（第一人称、前景遮挡） |
| 形式轴 | 自然写实（生活流、即兴感） | 轻度风格化 | 强形式感（对称、高对比、色块、荷兰角） |

**取值纪律**：不要五案都取中间值。至少一案在某一轴上打到极端端点，让选项边界清晰。

## 三、方向原型库

下面 12 个原型是「配方」，不是模板。每次按剧本剖析结果挑 5 个，**同一场次不许重复用同一原型**。

### P1《滞院长镜》——时间自己说话
- 概念：少切甚至不切，让动作在真实时间里发生完。
- 语法：平均镜头 8–15s，固定或极缓推移，中全景为主，画内纵深调度。
- 适合：人物情绪转折点、关系的静默时刻、文艺向。
- 风险：AI 视频模型单条时长有限，长镜需拆成多条生成后拼接，接缝风险高；大量坐着说话的段落会闷。
- 不选它的理由：信息密度低，爽点型内容撑不住。

### P2《贴近呼吸》——手持纪实
- 概念：摄影机像现场第三个人，跟着人跑、会喘、会晃、会被挡。
- 语法：手持跟拍 + 过肩，中近景，平均 3–5s，允许失焦和构图不稳，光走现场光源。
- 适合：纪实感的现实题材、追逃、混乱现场、底层叙事。
- 风险：AI 生成的抖动容易变成「果冻感」；过度晃会让人看不清内容。
- 不选它的理由：精致感弱，产品 / 品牌向素材不合适。

### P3《碎切冲击》——密度就是爽感
- 概念：把每一秒都塞满信息，靠剪辑变速制造推力。
- 语法：平均 1.5–2.5s，硬切，大量特写与局部插入镜，辅以跳轴与抽帧感。
- 适合：动作、爽点、反转、信息量大的开场、短视频前 10 秒。
- 风险：镜头数量暴涨（同等时长 2–3 倍条数），成本与时间翻倍；AI 每条起手不稳，短镜更难控制。
- 不选它的理由：不适合抒情，容易剪成躁。

### P4《冷眼旁观》——距离与留白
- 概念：摄影机退到很远，人只是环境里的一部分，情绪靠空间说。
- 语法：远景 / 大远景，固定机位，平均 5–8s，大量空镜与留白，声音占比重。
- 适合：悬疑开场、孤独主题、灾难 / 荒凉场景、转场缓冲。
- 风险：看不清人脸，靠 AI 生成的近景素材会不够用；滥用会显得空。
- 不选它的理由：有对白推进的段落会失效。

### P5《第一人称》——把观众按进画面
- 概念：镜头就是主角的眼睛，观众看到的就是主角看到的。
- 语法：POV + 前景遮挡（门框、树叶、人群背影），手持，中景到特写，平均 3–4s。
- 适合：惊悚、探索、游戏感、强代入的独白。
- 风险：主角自身不出画，主角表演（尤其是表情戏）无法呈现；长时间 POV 会疲劳。
- 不选它的理由：需要看到主角反应 / 双人对手戏时不成立。

### P6《秩序之框》——强形式构图
- 概念：每一个画面都像一张摄影作品，对称、居中、色块分明。
- 语法：对称构图 / 一点透视 / 框中框，固定或极缓推拉，平均 4–6s，色彩高度统一。
- 适合：广告、品牌片、作者性强的内容、压迫感场景。
- 风险：AI 对「严格对称」执行不稳，容易歪；过度形式化会削弱叙事。
- 不选它的理由：生活流、纪实题材会假。

### P7《明暗之争》——高对比黑色电影
- 概念：光比拉到极限，人脸半明半暗，阴影承担叙事。
- 语法：侧逆光 + 硬光切割，强弱明暗分区，中近景，缓慢横移。
- 适合：犯罪、悬疑、心理戏、夜戏。
- 风险：暗部细节 AI 容易糊；过度黑暗会让画面信息量不足。
- 不选它的理由：明亮、轻快的题材完全不适用。

### P8《群响交叠》——多线并置
- 概念：同一时间不同地点 / 不同人物的平行动作互相呼应。
- 语法：短 units 交叉剪辑，每段 2–4 镜成组，靠声音或动作做视觉母题串联。
- 适合：群像、悬疑铺垫、时间紧迫感。
- 风险：场景与角色多，AI 一致性压力极大，需要更多资产图锁身份。
- 不选它的理由：单线独角戏用不上。

### P9《一镜贯通》——伪一镜到底
- 概念：全段假装不停机，用遮挡黑场做接缝。
- 语法：连续运动 + 跟随，经过遮挡物时切瞬时遮蔽再利用下一镜衔接，平均段长 10–25s。
- 适合：炫技段落、紧张连续 Event、MV。
- 风险：接缝处人物 / 服装必须完全一致，任何不一致即穿帮，返工成本最高。
- 不选它的理由：几乎没有试错空间，工期紧别选。

### P10《素颜直述》——极简静帧流
- 概念：去掉一切花活，正面、平实、讲清楚。
- 语法：正面中景 / 近景，固定机位，平均 5–8s，切只在换说话人时发生。
- 适合：口播、访谈、教学、说明性内容。
- 风险：视觉吸引力最低，纯靠内容本身。
- 不选它的理由：要情绪、要氛围的片子不能用。

### P11《动势驱动》——物理运动主导
- 概念：画面永远在动，靠运动方向和速度带情绪。
- 语法：跟拍 / 环绕 / 穿越前景，大量运动中的元素（车流、雨、人群），平均 2–4s。
- 适合：追逐、 Sports、城市、产品动态展示。
- 风险：AI 对快速运动容易出畸变和肢体崩坏。
- 不选它的理由：静态重对话的段落浪费。

### P12《色彩叙事》——用色调度情绪
- 概念：每一段一个主色，色彩随情绪位移从冷到暖或反向。
- 语法：色块化的场景与服饰，灯光同步染色，中景到特写，平均 4–6s。
- 适合：MV、广告、青春 / 回忆线。
- 风险：AI 容易染色过度导致肤色失真；需要统一的调色流程约束。
- 不选它的理由：现实题材会失真。

## 四、从十二原型里选五案的五步法

1. **看类型** —— 喜剧 / 纪实避开 P7、P6；产品广告优先 P6、P12。
2. **看核心冲突性质** —— 冲突是「内心独白」→ P1、P4；是「人与人对撞」→ P2、P3、P8；是「人与环境」→ P4、P11。
3. **看体量** —— 场景多、人物多 → 避免 P8 / P9（成本爆炸）；单场独角戏 → P1、P5、P10。
4. **看模型能力** —— Seedance / 海螺的运动表现较好可选 P11；模型短线能力强再考虑 P3；尽量避免把 P9 交给新模型。
5. **凑够多样性** —— 检查五案在互斥五轴上是否真的散开；有两案落在同一格就换掉其中一个。

推荐一组「通用安全组合」（剧本信息不足时用）：P1 / P3 / P4 / P5 / P6 —— 五个方向差别最大，几乎不会重。

## 五、提案卡模板（照抄，别改字段）

```
===== 提案卡 [A] 《代号名》 =====
一句话导演概念：≤30 字，说清这一版「怎么拍」
镜头语法取向：主导景别 / 主导运镜 / 切换节奏 / 平均镜头时长
节奏曲线：0-15s 铺垫 → 15-40s 加压 → 40-60s 爆发 → 60-70s 余味
开场三镜样例：
  镜1（3s）大远景·固定·清晨薄雾中的码头，一艘船缓缓靠岸，人影只有指甲大小
  镜2（2s）特写·手持·铁链在缆桩上绷紧，锈屑抖落
  镜3（4s）中景·缓推·他从船舱走出，逆光只看得清轮廓
对本片的优势：……
代价与风险：……
预估成本：约 N 个镜头 / N 条生成
选它的理由：……
不选它的理由：……
```

**开场三镜样例的红线**：
- 必须写出**景别 + 运动 + 具体画面 + 秒数**，四要素缺一不可。
- 必须是剧本真实内容的镜头，不能是随便设计的漂亮画面。
- 五案的开场三镜必须肉眼可见的不同（两张卡里如果第一镜都是「大远景开场」就直接判重）。

## 六、交付前自检（人审 + 脚本）

人审清单：
- [ ] 恰好五案，代号 A–E 齐全。
- [ ] 五案名字有画面感、不重样、不是「方案一二三」。
- [ ] 五案在五轴上至少三轴落不同端点。
- [ ] 每案开场三镜四要素齐全且彼此不同。
- [ ] 每案都写了「不选它的理由」（没写 = 在哄用户）。
- [ ] 没有用计价或工期去暗示用户选某一案 —— 成本如实写，但不引导。

然后跑脚本：

```bash
python scripts/pitch_check.py <提案文件> [--n 5]
```

检查项：提案卡数量、字段完整性、名字重复、开场三镜相似度、平均镜头时长区分度、缺失的成本 / 风险字段。

未通过：**重做提案，不要进入关卡 3**。
