# 剧本剖析五维

关卡 1 的通读不是复述剧情，是**提取五个决定镜头设计的变量**。输出控制在半屏内 —— 用户要的是判断，不是故事梗概。

## 维度 1：类型与受众

回答：这部片子的镜头语汇边界在哪？

- 广告 / MV → 允许形式化、允许跳切、允许主观表意更强的手法（P6、P12）。
- 纪实 / 现实题材 → 手持、长镜、自然光，禁止过度雕琢的构图（P2、P10）。
- 悬疑 / 犯罪 → 明暗与遮挡叙事（P7、P4）。
- 短剧 / 快节奏叙事 → 钩子密度优先，镜头宁短勿长（P3）。
- 教学 / 口播 → 讲清楚压倒一切（P10）。

输出格式：`类型：XXX ｜ 允许：XXX ｜ 禁止：XXX`

## 维度 2：核心冲突

回答：哪一場是全片最不能含糊的？

找到那一场之后，给五案立一条共同底线：**任何提案都必须保证这一场成立**。如果某原型会让这场失效（例如核心冲突是双人对手戏，而某案是全程 POV），就在该案的风险里明写。

输出格式：`核心冲突场次：第 X 场 · XXX ｜ 所有方案底线：XXX`

## 维度 3：人物弧线

回答：主角在这一段里，状态从哪走到哪？

状态位移的方向决定该给什么景别：
- **向内收**（醒悟、崩溃、下定决心）→ 近景 / 特写比例提高；
- **向外拓**（进入新环境、获得力量、关系扩展）→ 远景 / 全景比例提高；
- **关系变化**（和解、决裂）→ 正反打与双人中景比例提高。

输出格式：`弧线：XXX → XXX ｜ 建议景别重心：XXX`

## 维度 4：爽点 / 钩子链

回答：情绪高点分别在第几秒？

在时间轴上标出 3–5 个高点，五案的「节奏曲线」都由这条链推导。注意定义爽点类型：
- **信息型**（真相揭开）→ 需要反应镜 + 停顿；
- **动作型**（出手、撞击）→ 需要过程镜和冲击帧；
- **情绪型**（重逢、告别）→ 需要留白和长镜；
- **反转型**（立场翻转）→ 需要一个「抽离的静帧」给观众反应时间。

输出格式：`爽点链：15s（信息）/ 40s（动作）/ 62s（反转）`

## 维度 5：时空结构

回答：跳了多少次，需不需要补桥接？

- 场景数 ≤2 且时间连续 → 不需要桥接。
- 场景数 3–5 → 每处跳跃至少 1 个桥接镜。
- 场景数 >5 或有时间跳跃 → 必须建立「空间标识镜」（每个场景一个定场）或「时间标识镜」（钟、光线变化、日历）。
- 集首 / 片首 → 需要衔接上一集的入场镜，不能第一镜就直接站在对话中。

输出格式：`场景数：N ｜ 需补桥接：N 处 ｜ 需定场镜：N 个`

---

## 剖析输出模板（照抄）

```
===== 剧本剖析 =====
类型：XXX ｜ 允许：XXX ｜ 禁止：XXX
核心冲突：第 X 场 · XXX ｜ 所有方案底线：XXX
人物弧线：XXX → XXX ｜ 景别重心：XXX
爽点链：15s（信息型）/ 40s（动作型）/ 62s（反转型）
时空结构：N 个场景 ｜ 需补桥接 N 处 ｜ 需定场镜 N 个
→ 据此，本次五案取：P_ / P_ / P_ / P_ / P_
```

最后一行是承上启下的关键 —— 把选型的理由摆给用户看，用户可以在这一层就纠偏（「别选 P9，工期不够」），避免做完五案才推翻。
