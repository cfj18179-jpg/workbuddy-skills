# 审查与质量红线

## 一、绝对红线（出现即拒收，必须回改）

| # | 问题 | 判据 | 修复 |
|---|---|---|---|
| R1 | 台词被删改 | 剧本台词在产出里找不到或字面不一致 | 未按用户确认不得改；要改动必须交付原版 + 优化版两版 |
| R2 | 台词没落在代码块 | 台词只出现在核对表 / 说明文字，不在可执行代码块正文 | 逐条搬进对应 SHOT 正文 |
| R3 | 台词张冠李戴 | 台词挂到了别的角色或别的镜号 | 按剧本逐句重置归属 |
| R4 | 五案雷同 | 两案的主导景别 / 运镜 / 平均时长几乎一致 | 换掉其中一案的原型，回到关卡 2 重做 |
| R5 | 自行代选方案 | 没等用户回复就展开了完整版 | 停下，回到关卡 3 |
| R6 | 画面内有未交待的光源 | 出现「氛围光」「柔光」等无来源描述 | 补光源位置与类型（见 `references/04`） |
| R7 | 空词 | 唯美 / 史诗感 / 高级感 / 有质感 / 电影感 | 换成可拍摄的具体内容 |
| R8 | 有台词缺失 | 剧本中的对白行在产出里完全没有对应 SHOT | 补镜或在现有 SHOT 挂台词 |
| R9 | 时间码断裂 | 起止时间不连续或合计与目标时长偏差 >5% | 重排时间码 |
| R10 | 因果链断裂 | 出现能量 / 动作 / 状态的「瞬移」 | 补「因→过程→果」过程镜 |

## 二、常见软性问题（告警，尽量修）

- 连续三镜同景别无内容变化 → 补插入镜或合并。
- 运镜无动机 → 补「为了跟随 / 揭示 / 强调 XX」，写不出就改固定。
- 声音列全为空 → 声音是分镜的一部分，至少写环境音。
- 口型镜超过 4 秒 → 拆成两条，后半切走。
- 负面约束写成否定句 → 改成名词列举。
- 提示词条数与镜号数量对不上 → 补或删，保持一一对应。
- 同一角色跨镜描述不一致（发色、外套颜色）→ 统一到一份「角色锚点描述」并每次复制。

## 三、审查报告模板

```markdown
===== 交付审查报告 =====
文件：<产出文件路径>
目标时长：90s ｜ 实际合计：89s ｜ 偏差：1.1% ✅
镜数：26 ｜ 建议区间 23–30 ✅
最长单镜：7s ｜ 口型镜最长：4s ✅
提示词条数：26 / 镜数 26 ✅
台词双指标：全文 18/18 ✅ ｜ 代码块内 18/18 ✅
空词扫描：0 处 ✅
光源缺失：0 处 ✅
结论：PASS —— 可交付
```

结论只有两种：**PASS（可交付）** 或 **FAIL（回改）**。不存在「基本通过」。

## 四、被人挑刺时的处理顺序

用户说「不对」时，按这个顺序排查，不要立刻重做全部：

1. **方向错** → 回到关卡 3 重新选案（保留原有五案，只需用户指明）。
2. **方向对、执行跑偏** → 检查是否真的沿用了该案的镜头语法；常犯的错是提案写「远景」、展开时又切回正反打。
3. **某几镜不对** → 只改那几镜，重跑审查即可。
4. **说不清哪里不对** → 请用户指出一个具体镜号，单点问：景别？运镜？节奏？内容？问清再改。
