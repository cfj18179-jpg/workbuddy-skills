# 镜头语法与运镜库

写分镜表和提示词时的术语标准。统一用中文，括号备注英文仅在与 AI 模型已知词冲突时使用。

## 一、景别（Shot Size）

| 中文 | 建议写法 | 画面界定 | 常见用途 |
|---|---|---|---|
| 大远景 | ELS | 环境为主，人极小或不可辨 | 定场、留白、压迫感 |
| 远景 | LS | 人物全身在环境中占约 1/3 | 交代位置关系 |
| 全景 | FS | 人物全身填满画框 | 动作全过程 |
| 中景 | MS | 腰部以上 | 对话、常规叙事 |
| 中近景 | MCU | 胸部以上 | 情绪对话、正反打 |
| 特写 | CU | 头肩 / 面部 | 情绪落点、反应 |
| 大特写 | ECU | 眼、嘴、手、物件局部 | 强调、插入镜 |

**纪律**：分镜表里每一镜都必须写清景别；连续三镜同景别而无内容变化，视为无效冗余，应合并或补一个插入镜。

## 二、镜头运动（Camera Movement）

| 中文 | 说明 | 提示词写法要点 |
|---|---|---|
| 固定 | 机位不动 | 直接写「固定机位」，不要写「静止画面」（AI 会理解成完全无元素运动） |
| 推 Push in | 机位前移逼近主体 | 写「缓慢推近至 XXX」 |
| 拉 Pull back | 机位后退揭示环境 | 写「后拉揭示 XXX」 |
| 摇 Pan | 机位不动，横向转 | 写「从左向右摇至 XXX」 |
| 俯仰 Tilt | 机位不动，纵向转 | 写「自下而上仰至 XXX」 |
| 移 Track / Dolly | 机位横向平移 | 写「横向跟移」 |
| 跟 Follow | 跟拍移动主体 | 写「跟拍 XX 的背影」 |
| 环绕 Arc / Orbit | 绕主体旋转 | 风险较高，AI 易畸变，谨慎使用 |
| 升降 Crane / Boom | 垂直位移 | 写「自地面向上升起」 |
| 手持 Handheld | 呼吸感、轻晃 | 写「轻微手持呼吸感」，不要写「剧烈摇晃」 |
| 斯坦尼康 Steadicam | 平滑跟随 | 中长镜跟随的首选 |

**两点注意**：
1. 一个镜头**只给一个主导运动**。同时写「推 + 摇 + 手持」会让 AI 全做或者全乱。确有复合需求时，写成「先 X 后 Y」的时序。
2. 运动必须有**动机**（跟谁、看向什么、揭示什么），无动机的运动会被判定为空转。

## 三、角度与视线高度

| 写法 | 效果 |
|---|---|
| 平视 Eye level | 中性、平等 |
| 俯拍 High angle | 削弱、孤立、渺小 |
| 仰拍 Low angle | 压迫、权威、力量 |
| 过肩 Over shoulder | 对话空间关系 |
| 荷兰角 Dutch angle | 失衡、危机、心理不稳（**仅在明确需要时使用，不可默认**） |
| 鸟瞰 Top / Bird's eye | 格局、图案感、抽离 |
| 虫视 Worm's eye | 极端仰视、怪异 |

## 四、构图

- 三分法 / 中心对称 / 引导线 / 框中框 / 前景遮挡 / 负空间留白 / 镜像与反射 / 深度分层（前中后景）
- 写提示词时**只挑一个主导构图**描述，堆三个以上等于没说。
- 「前景遮挡」是 AI 视频里最稳的层次手段：写「前景右侧 XX 略微遮挡画面边缘」即可造出空间感。

## 五、转场

- **默认硬切（Cut）**。写「溶解」「叠化」「闪光转」这类特效转场前先问用户，AI 对这些执行很差。
- 允许的黑场：段落感需要时用极短黑帧衔接，但要在备注写明用途。
- 匹配剪辑（Match cut）：靠形状 / 动作 / 视线方向承接前后镜，是最推荐的「高级」转场手段。
- **跳切（Jump cut）**：同一主体同景别直接切，用于压缩时间和制造不安，须显式标注动机。

## 六、光（必须有物理来源）

| 光源类型 | 写法示例 |
|---|---|
| 自然日光 | 清晨低角度侧逆光穿过窗棂，在地面投出栅格阴影 |
| 阴天散射 | 阴天柔和散射光，无明显阴影，天光偏冷 |
| 室内实用光 | 画面右侧桌灯为唯一光源，向外 1 米迅速衰减 |
| 霓虹 / 城市光 | 街对面霓虹招牌的红蓝交替光扫过侧脸 |
| 火光 | 篝火在下方打出跳动的暖橙光，人脸明暗随火焰抖动 |
| 屏幕光 | 手机屏幕自下而上照亮下巴与鼻底 |

**禁止**：无来源的「氛围光」「柔和光」「电影级打光」「逆光轮廓」——没有光源位置与方向，AI 会自由发挥，同一角色每帧亮度都不一样。

## 七、写分镜时最常犯的五个错

1. **只写情绪不写画面**：「他很难过」→ 改成「他盯着桌上的照片，手指在边缘反复摩挲，喉结动了一下」。
2. **景别与焦距混用**：分镜表的景别写范围（MS/CU），不要写「85mm」（除非已确定镜头组）。
3. **运镜无动机**：每个运动后面都要跟「为了揭示 / 跟随 / 强调 XX」，写不出动机就改成固定。
4. **同景别堆砌**：连续三个中景对话而无视线变化、无插入镜 —— 补一个物件特写或听者反应。
5. **忘了声音列**：声音不是备注，是分镜的一部分；没有声音设计的分镜表是不完整的。
