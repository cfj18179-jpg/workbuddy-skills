# 分镜表与提示词交付模板

## 一、分镜表（设计层 · Markdown）

```
===== 分镜表 · 第 X 集 / 第 X 段 =====
方案依据：选定 [C] 案《代号名》（如跨案组合，写「主案 C + 借用 B 案的 XXX」）
目标时长：90s ｜ 画幅：16:9 ｜ 目标模型：Seedance 2.5
镜头语言基调：远景环境为主 / 固定机位 / 平均镜头 6s / 硬切

| 镜号 | 时间码 | 时长 | 景别 | 运镜 | 画面内容 | 台词 | 声音 | 备注 |
|---|---|---|---|---|---|---|---|---|
| 01 | 00:00-00:05 | 5s | 大远景 | 固定 | 清晨薄雾中的旧码头，铁壳船缓缓靠岸，人影只有指甲大小 | — | 汽笛远鸣、缆绳吱呀 | 定场镜 |
| 02 | 00:05-00:08 | 3s | 特写 | 手持 | 铁链在缆桩上绷紧，锈屑簌簌抖落 | — | 金属摩擦声放大 | 插入镜 |
| 03 | 00:08-00:13 | 5s | 中景 | 缓推 | 他从船舱口走出，逆光只看得清轮廓，右手插在工装口袋里 | ※台词：他（画外，2s）："三年了。" | 脚步落在铁板 | 主角登场 |
```

列填写规范：

| 列 | 要求 |
|---|---|
| 镜号 | 两位数字，01 起；有插入镜时用 03A / 03B |
| 时间码 | 起止，连续不跳空；合计必须等于目标时长 ±5% |
| 时长 | 整数秒；口型镜 ≤4s；长镜允许 6–15s 但要在备注写依据 |
| 景别 | 按 `references/04` 的标准七档，不写焦距 |
| 运镜 | 单一主导运动 + 动机；复合运动写「先 X 后 Y」 |
| 画面内容 | 主体 + 动作 + 环境 + 光（含来源）；不写情绪形容词 |
| 台词 | 一字不差引用剧本；无台词写 — |
| 声音 | 必填。环境音 / 动作音 / 音乐走向；写 — 视为未完工 |
| 备注 | 定场 / 桥接 / 补过程镜 / 需参考帧编号 / 拼接接缝说明 |

## 二、可执行代码块（实操层 · 提示词）

**这一块才是真正会被复制粘贴给模型的東西**，台词必须写在里面。

````markdown
## 可执行提示词（Seedance 2.5 · 16:9）

```
【通用约束】
画幅 16:9，明亮的真实打光，光源须有明确物理来源；人物身份与服装跨镜一致；
默认硬切，不使用溶解叠化。
负面：变形的手指、多余肢体、字幕、水印、忽明忽暗、服装突变。

【SHOT 01 ｜ 5s ｜ 大远景·固定】
@旧码头_清晨。清晨薄雾中的废弃铁壳码头，一艘锈迹斑斑的小型货船自画面右侧缓缓靠岸，
船头缆绳抛出。日光尚未穿透雾气，整体为冷灰蓝的柔和散射光，无固定阴影方向。
画面三分法，码头栈桥自左下延伸至右上形成引导线，人物尚未出现。机位固定，群鸟自画面上方掠过。约 5 秒。
不要出现：字幕、水印、闪烁、多余的船只。

【SHOT 02 ｜ 3s ｜ 特写·手持】
@铁缆桩。锈迹斑斑的铁链在缆桩上骤然绷紧，金属表面震落的锈屑簌簌落下，
一滴水自铁链下方滴落。侧上方的清晨冷光擦过铁链上缘形成细窄高光，背景沉在雾中虚化。
大特写，浅景深，轻微手持呼吸感。约 3 秒。
不要出现：变形金属、扭曲的结构、字幕。

【SHOT 03 ｜ 5s ｜ 中景·缓推】
@他_工装版。三十来岁的男人从船舱口走出，穿洗旧的藏青色工装外套，左手拎帆布包，
右手插在外套口袋。身后舱内是暗的，他被逆光照亮，只能看清轮廓与肩线。
自幕后明亮的天空作为唯一光源，形成强逆光剪影。中景，略低于视线，缓慢推近至胸部以上。约 5 秒。
※台词：他（画外，2s）："三年了。"
不要出现：五官崩坏、多余的肢体、服装突变、面部忽明忽暗。
```
````

代码块纪律：
- 代码块标记用 ```（内含代码块的示例用 ```` 包裹，如上所示）。
- 每一条以 `【SHOT NN ｜ Xs ｜ 景别·运镜】` 开头。
- **台词行必须写在 SHOT 正文里**：`※台词：角色（口型/画外/群杂，时长）："原文"`。
- 通用约束与负面约束写在块首，不每条重复（模型不支持的才删）。
- 有资产图时用 @引用锁身份；纯文生时把角色的服装 / 发色 / 体型写全。

## 三、文末核对区（辅助，不能替代代码块）

```
===== 台词核对表 =====
| # | 来源 | 角色 | 台词首句 | 落位镜号 | 全文有? | 代码块有? |
|---|---|---|---|---|---|---|
| 1 | 第 X 场 | 他 | "三年了。" | SHOT 03 | ✅ | ✅ |

===== 场景 / 道具连续性 =====
| 元素 | 出现镜号 | 状态变化 | 备注 |
|---|---|---|---|
| 旧怀表 | 03 / 17 / 22 | 取出 → 摩挲 → 放下 | 需同一参考帧 |
```

**核对表只是给人类看的台账。台词只在核对表出现而代码块里没有 = 台词全丢，审查直接判不通过。**

## 四、文件命名与落盘

建议落在工作目录下，命名：
- `<项目名>_第X集_五案提案.md`
- `<项目名>_第X集_分镜表_选定[C].md`
- `<项目名>_第X集_审查报告.md`

审查报告由 `storyboard_check.py --report` 生成，作为交付附件一并给出。
