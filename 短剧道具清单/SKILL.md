# 短剧道具资产清单与静物提示词

> **卡面格式规范不在这里**——四视图静物卡（左上正面／右上背面／左下侧视厚度／右下局部工艺）的排版句与质感句，以 `全资产大师` 技能里的「道具资产」协议为准。本技能只负责**怎么把道具挖全、怎么分类、怎么交付**。

## 何时用

用户给出剧本并要求「整理道具资产 / 道具提示词 / 所有道具」。常见前提：项目里**只有零散几张道具图和一份十几项的道具文件**，而剧本里其实有几十上百件道具。

## 一、先把道具挖全（关键，别靠印象）

三步扫描剧本全文（用 markitdown 或已有 md），三路交叉验证：

1. **关键词直扫**：把器物类词表一次性跑一遍并统计词频——火钳/铲/锹/耙/钩/竿/线/漂/饵/网/兜/笼/桶/盆/篓/筐/袋/箱/罐/盒/秤/砣/账本/算盘/算盘/钱/票/钥匙/灯/手电/头灯/帽/巾/套/衣/鞋/灯/扇/炉/锅/冰箱/彩电/车/船/桨/摩托/电话/药/礼盒/鞭/红纸……词频直接给出优先级。
2. **器物后缀扫描**（补漏最有效）：正则 `[\u4e00-\u9fa5]{1,4}(桶|袋|车|船|网|箱|罐|盒|灯|秤|本|钩|竿|刀|锅|碗|杯|壶|机|表|绳|篮|篓|筐|盆|缸|扇|衣|鞋|帽|巾|镜|牌|证|票|钱|款|笔|钳|铲|锹|耙|钥匙)`，按出现次数排序。**注意**：单靠「量词短语」统计（一条金枪鱼/两只青蟹）会把**渔获当道具**、却漏掉「他拿了A、B、C」这类并列句，所以两种扫描都要跑。
3. **动作句上下文**：对每个候选词抓上下文句子（`△…拿了…`、`…掏出…`、`…提着…`、`…递上…`），用来判断**剧情用途**与**是否真的作为道具出现**（避免把台词里的比喻当道具）。同时扫「N-2 地点：…人物：…」的场景头，能定位道具出现在哪一集哪一场。

**判定口径**：能上镜、能被人物拿/放/看/吃/用的实体物件 = 道具；台词里的比喻、纯声音（喇叭声）不算。

## 二、分类（固定九类，按剧组采购口径）

1. 赶海·滩涂工具（铲、耙、锄、簸箕、手套）
2. 钓具·渔具（竿、线、钩、饵、网、抄网、鱼护）
3. 装载·运载与称重·交易（桶、篓、筐、麻袋、扁担、磅秤、杆秤、账本、算盘、计算器）
4. 载具·船只与车辆（渔船、橹桨、挂机、三蹦子、摩托、桑塔纳、游艇）
5. 生活器物·家电（彩电、冰箱、电风扇、围裙、脸盆架、收音机、凉席、灶炉）
6. 雨具·照明·劳保（雨衣、斗笠、蓑衣、草帽、头灯、手电）
7. 剧情关键·道具与票据（钥匙、欠条与印泥、现金、彩礼捆、厂牌、礼物道具）
8. 食材·海货静物组（爆桶组合、满筐、堆积奇观）
9. 系统与特效类（系统产物、特效参考物）

## 三、每项的字段（缺一不可）

`编号` `名称` `类别` `来源` `剧情用途` `规格（尺寸）` `材质与年代痕迹` `AI图片提示词`

**「来源」必须二选一并写清依据**：
- **剧本明写**：注明集数/场次或台词线索（如「第16集·杂物房拿了沙铲、火钳、手套」）。
- **合理补足**：剧本未明写但同期拍摄必备（如滩涂三齿耙、泡沫保鲜箱、蒲扇凉席），标注后让用户自行取舍。
> 这一条是客户信任的关键——绝不要把补足项伪装成剧本原物。

## 四、提示词模板（逐字内嵌，一项一段）

```
1998年中国沿海渔村题材{类别}，{剧情用途}，{规格}“{名称}”。整体形制、材质和年代痕迹：{细节}。四视图静物资产卡：左上正面完整视图，右上背面完整视图，左下标准侧视图展示厚度，右下局部工艺与磨损细节特写。纯白或极浅灰背景，柔和顶光；禁止人物、手、人影、文字、标识和水印。真人电影级静物摄影，材质纹理清晰可触，8K超精细。
```

**{细节} 的写法**（决定成片质感）：材质＋工艺＋**使用痕迹**三件套。例：`深蓝聚乙烯水桶、铁质提梁、桶身加强筋，桶壁有刮花与白化、提梁生锈，桶底沾泥沙，内壁有水垢与鱼腥痕迹`。**必须有磨损/包浆/盐渍/锈斑**，否则出图会像全新的现代商品。

**年代铁律**：1998 年可出现的形制；文字一律「不可读剪影或留白」；禁止现代物品与商标。

## 五、交付结构（四段式）

```
〇 本册怎么用（只交付提示词不生成图片 / 四视图固定排版 / 年代铁律 / 来源标注 / 出图顺序建议）
一 通用规范（四视图排版句 + 质感基准 + 统一限制负向词 + 分格一致性）
二 道具总目录（表格：编号｜名称｜类别｜来源｜剧情用途｜出图状态）
三 分类明细（3.1–3.9 每类下列逐项卡：字段 + 提示词）
四 交付说明（总数与新增数 / 命名规范衔接 / 可继续扩的方向 / 动作戏要不要补使用状态参考图）
```

**编号衔接（重要）**：若项目里已有出图的道具，**沿用其原编号并原样保留其提示词**，新增项从其后续号继续排；文件名规范提示为 `P编号 名称.png`，方便分镜表直接引用。

## 六、出图顺序建议（写进交付）

先出 **10–12 件高频核心道具**（每类挑 1–2 件）把质感与色温定下来，其余按同一套光位批量出，避免整套图色温不一致。

## 七、技术路径（本机已验证）

1. 剧本转文本：`markitdown`（隔离 venv：`C:\Users\EDY\.workbuddy\binaries\python\envs\default\Scripts\python.exe`）。
2. 生成交付：走 `tencent-local-office-edit` 的 `edsdk.py` → `create_doc` 拿 file_id（**必须 `grep -oE "file_id=[A-Za-z0-9_]+" | head -1 | cut -d= -f2`，否则报 document is not open**）→ `doc_insert_markdown`（长中文用 `--json-file` 传 base64）→ `save_file`。
3. **坑**：写生成脚本时，Python 字符串里**不要用 ASCII 直引号做中文引号**——会直接把脚本写坏；中文引号统一用「」。同理也别写「先替换再复查」的半自动修引号脚本，容易把 `r"..."` 也改掉。
4. 校验：`markitdown` 反读 docx，核对「AI图片提示词」段数 == 道具总数。
