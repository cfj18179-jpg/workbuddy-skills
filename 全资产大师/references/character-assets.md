## 万能题材发型规则

发型必须符合角色所处时代与身份，禁止与时代脱节。

| 题材 | 发型 |
| --- | --- |
| 古装/历史（先秦—清） | 束发、发髻、发冠、簪笄、胡辫；严禁现代短发与碎刘海 |
| 民国 | 分头、油头、麻花辫、齐耳短发、烫卷发 |
| 现代/都市/校园/职场 | 任意符合人物设定的现代发型（短发、长发、寸头、莫西干、烫染均可） |
| 科幻/赛博朋克 | 可染色、剃边、植入物、机械义体、发光发丝 |
| 末世/军旅 | 板寸、脏辫、随意束发、布巾包头 |
| 西幻/魔幻 | 长发披散、编辫、兽角、精灵耳饰 |
| 仙侠/玄幻 | 束发、道髻、长发披风式 |

核心硬规则：

1. 发型必须服务于"角色所处的时代与世界观"，不允许穿越违和。
2. 历史剧/古装剧严格禁止现代短发碎发。
3. 任何题材都必须明确写出发型结构（长度、颜色、束法、是否束起、刘海走向）。
4. 禁止只写"短发"或"长发"，必须细化（如：偏分齐耳短发、低马尾束发、油背头）。

## 万能服装系统

服装层次采用"从内到外 + 腰部 + 下肢 + 足部"六层结构，内容随题材变化：

| 题材 | 六层 |
| --- | --- |
| 古装 | 内衣中衣 / 外袍短褐 / 披风大氅 / 玉带蹀躞 / 战裙裤装 / 靴或草鞋 |
| 民国 | 白衬衫 / 长衫或西装马甲 / 大衣风衣 / 皮带怀表链 / 西裤或旗袍 / 皮鞋绣鞋 |
| 现代职场 | 衬衫T恤 / 西装外套或针织 / 风衣大衣 / 皮带腰封 / 西裤牛仔裙装 / 皮鞋运动鞋 |
| 街头潮流 | 贴身内搭 / 连帽卫衣或机能上衣 / 棒球外套或机能马甲 / 战术腰带 / 工装裤 / 老爹鞋高帮靴 |
| 科幻赛博 | 紧身内衬 / 智能纤维外套 / 发光线缆披风 / 战术腰带+数据接口 / 机能裤 / 碳纤维战靴 |
| 末世废土 | 破布内搭 / 拼接皮革背心 / 防尘斗篷 / 弹药腰带 / 加固护膝裤 / 缠布军靴 |
| 西幻 | 亚麻内衫 / 锁子甲或皮甲 / 兜帽斗篷 / 武装腰带 / 紧身护腿 / 皮革长靴 |
| 校园 | T恤衬衫 / 制服外套或卫衣 / 校服外套 / 普通腰带 / 校裤裙装 / 帆布鞋 |

特殊状态层（任意题材通用）：伤势 / 束缚 / 污垢 / 战损 / 雨水 / 血迹 / 改装义体 / 纹身 / 妆造 / 配饰。

## 角色提取必填字段

【角色基础信息】：角色名、身份/职业/阵营、年龄段、性别、所属时代/世界观。

【视觉识别系统 · 基础面容锚点】（必填，禁止空泛形容词）

- 脸型（长/圆/方/窄/心形/菱形）
- 眉形（平直/上扬/浓眉/疏眉/剑眉）
- 眼型（狭长/圆眼/凤眼/桃花眼/下垂眼/三白眼）
- 鼻型（高直/宽鼻/驼峰/细直/塌鼻）
- 唇形（薄唇/厚唇/唇峰明显/嘴角上扬或下垂）
- 骨相（颧骨/下颌线/眉骨/苹果肌）
- 肤色（冷白/暖白/小麦/古铜/苍白/病态）
- 局部识别点（痣/疤/胎记/雀斑/纹身/义体接口/疤痕）

【发式系统】：长度与束法（必须符合时代规则）+ 颜色与染色 + 头饰/帽子/头盔/义体 + 鬓角与刘海走向。

【服装层次】：按六层结构填写——内 / 外 / 套 / 腰 / 下 / 足。

【特殊状态】（如适用）：伤势 / 束缚 / 污垢 / 配饰 / 妆造 / 战损 / 改造。

## 人物三视图构图规范

每条角色提示词必须强制包含四宫格三视图构图：

1. 左侧三分之一：上下等分排布——角色超大正面，面部特写（展示五官细节、表情、皮肤纹理、妆造/伤痕）；下方是角色侧面 90 度超大面部特写。
2. 右侧三分之二：依次展示——全身正面（无头部出镜，T-pose 或自然站姿，展示服装前片与结构）；全身背面（展示服装后片、发型后视、披风/外套后摆）；侧身 90 度（无头部出镜，展示体型轮廓、服装厚度与层叠关系）。

背景统一：白色背景或浅灰摄影棚背景。

## 提示词组织顺序

[时代/世界观] + [身份] + [性别年龄] + [全局参考风格] + [基础面容锚点完整描述] + [发式与头饰] + [服装从内到外六层] + [特殊状态] + [姿态：双手自然下垂，站姿自然，面容平静] + [四宫格构图指令] + [画质与背景要求]

字数：300-500 字。

## 禁止事项

1. 古装题材禁止任何现代短发碎发；其他题材发型必须与时代严格匹配。
2. 角色提示词中禁止出现武器/法宝/道具/坐骑（须独立建道具卡）。
3. 禁止空泛形容词（"帅气""美丽""威严"必须转为具体五官描述）。
4. 禁止比喻/拟人（"如寒霜般的眼神"应转为"眼尾下垂，眼神冷峻"）。
5. 同一角色不同形态不得改变面容（仅允许改变服装/伤势/年龄/妆造）。
6. 不允许角色与场景元素混写。
