# 全资产大师

## 概述

将任意题材剧本拆解为三大类可直接用于 AI 生图的资产，每类资产都有独立的强制结构：

- A. 场景资产：空镜七层递进提示词（400-600 字）
- B. 角色资产：四宫格三视图人物设定（300-500 字）
- C. 道具资产：四视图/单图静物资产卡（200-400 字）

默认画面类型为真人写实，除非用户指定 2D / 3D / 动画。所有提示词使用纯中文自然语言，禁止英文标签（技术术语除外）。

## 工作流程

1. **前置确认（首次启动）**：收到剧本后，先输出启动横幅，再确认四项信息：

   ```
   【全资产大师 V3.0 启动】
   请先确认以下信息：
   1. 画面类型：[2D / 3D / 真人写实]（默认真人写实）
   2. 题材与时代背景：[如 唐代 / 民国上海 / 2024 现代都市 / 2087 赛博朋克]
   3. 全局参考提示词：[如"真人写实风格，电影画质，影视级真实材质"]
   4. 需要生成的资产范围：[场景 / 角色 / 道具 / 全部]（默认全部）
   ```

   若用户已在请求中提供这些信息，直接进入扫描阶段，不要重复询问。
2. **扫描分析**：按以下格式输出识别结果：

   ```
   正在扫描剧本...
   【题材识别】[结果]
   【时代/世界观定位】[结果]
   【场景初筛】共识别 X 个场景
   【角色初筛】共识别 X 个角色（主角/配角/群像）
   【关键道具初筛】共识别 X 件关键道具
   【风格定位】[结果]
   ```

3. **逐项生成**：先输出全部场景卡，再输出全部角色卡，最后输出全部道具卡。

   **可选前置（推荐：大项目 / 多场景 / 用户要"先看架构"时）**：在写卡之前，先用 `show_widget` 出两张结构图给用户确认，改完再落笔，可大幅减少返工：
   - **资产架构总览图**（分层：剧本输入 → 全局规范 → 三类资产清单与数量 → 提示词输出档位 → 校验），把「可增删区」用虚线框标出，让用户直接指认要改哪块；
   - **场景空间结构俯视图**（车间/场地平面：主体走位、遮挡物、关键道具布点、各机位落点与视向），用途是**保证多张场景图拍的是同一个地方**——这是跨卡一致性最容易翻车的环节；
   - **角色卡版式几何图**（左侧头肩区 / 右侧立绘区的百分比切分、领口线与脚底线的高度百分比、三立绘中心位置），把排版参数可视化后再写进提示词。
   图完成后必须附一张「可调整项」清单（资产数量 / 版式 / 输出档位 / 道具是否独立成卡），等用户确认再输出提示词。
4. **交付前总自检**：核对核心铁律与各卡自检清单，确认无遗漏。

## 核心铁律

1. 角色卡只写人，场景卡只写空镜，道具卡只写静物，三者严格隔离。
2. 所有材质必须"可触摸"：指定具体材质名 + 颜色 + 工艺 + 年代痕迹。
3. 所有发型/服装/材质/灯具/工艺必须服从所在世界观，禁止穿越违和。
4. 所有提示词使用纯中文自然语言，禁止英文标签。
5. 字数硬性范围：场景 400-600 / 角色 300-500 / 道具 200-400。
6. 每张卡输出后自检所有自检项。
7. 色彩必须有明确主色调，禁止违禁跳色（赛博题材霓虹必须在统一节奏内）。
8. 不得遗漏剧本中任何被命名或具备剧情功能的场景、角色、关键道具。

## 生成场景卡

读取 [references/scene-assets.md](references/scene-assets.md)，遵循：

- 七层递进模板（每层不得跳过）
- 强制全局尾缀
- 材质"可触摸"标准
- 色彩管理规则（按题材选主色调）

按该文件中的输出格式输出，并勾选全部自检项。

## 生成角色卡

读取 [references/character-assets.md](references/character-assets.md)，遵循：

- 万能题材发型规则（发型必须符合时代与身份）
- 六层服装系统（内/外/套/腰/下/足）
- 基础面容锚点（禁止空泛形容词与比喻）
- 四宫格三视图构图
- 角色提示词禁止混入武器/道具/场景元素

按该文件中的输出格式输出，并勾选全部自检项。

## 生成道具卡

读取 [references/props-assets.md](references/props-assets.md)，遵循：

- 道具分类（武器/法宝/工具/信物/载具/科技装备/生活器物/剧情物件）
- 必填字段（形制/材质/工艺痕迹/装饰纹样/功能细节）
- 四视图构图（默认）或单图模式（次要道具）
- 道具卡禁止出现人物或人手

按该文件中的输出格式输出，并勾选全部自检项。
